### 3.1.1 Dijkstra：非负权最短路

[完整代码：3.1.1 Dijkstra：非负权最短路.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.1.1%20Dijkstra%EF%BC%9A%E9%9D%9E%E8%B4%9F%E6%9D%83%E6%9C%80%E7%9F%AD%E8%B7%AF.cpp)

**用途与条件**：有向或无向非负权图，从 s 出发求最短路。g[u] 中保存 {v,w}。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。

**复杂度**：二叉堆实现 O((n+m)log(n+m))；空间 O(n+m)。

**易错点**：禁止负边。不可达返回 INF。要求有限答案严格小于 INF；本实现跳过达到哨兵的距离。无向边需添加两个方向。

```cpp
const i64 INF = (1LL << 62);

// 求源点 s 到各点的最短距离，g[u] 存 {终点,边权}，顶点使用 1..n。
// 要求边权非负，返回 dist[1..n]，不可达为 INF，有限答案须小于 INF；不修改图。
// 堆实现时间 O((n+m)log(n+m))，空间 O(n+m)。
vector<i64> dijkstra(const vector<vector<pair<int, i64>>>& g, int s) {
    vector<i64> dist(g.size(), INF);
    dist[s] = 0;
    priority_queue<pair<i64, int>, vector<pair<i64, int>>, greater<pair<i64, int>>> q;
    q.push({0, s});
    while (!q.empty()) {
        auto [du, u] = q.top();
        q.pop();
        if (du != dist[u]) continue;
        for (auto [v, w] : g[u]) {
            assert(w >= 0);
            if (w >= INF - du) continue;
            if (dist[v] > du + w) {
                dist[v] = du + w;
                q.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

**调用与说明**：vector<vector<pair<int,i64>>> g(n); g[u].push_back({v,w}); auto dist=dijkstra(g,s);

### 3.1.2 0-1 BFS

[完整代码：3.1.2 0-1 BFS.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.1.2%200-1%20BFS.cpp)

**用途与条件**：边权只有 0 或 1 时，用双端队列求最短路。0 权边入队首，1 权边入队尾。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。

**复杂度**：时间 O(n+m)，空间 O(n+m)。

**易错点**：不要在入队时标记已访问，距离仍可能改进。这里在第一次有效出队时确定最短距离。

```cpp
// 求源点 s 的 0/1 边权最短路；g 使用 1 下标，边记录为 {终点,0或1}。
// 返回各点距离，不可达为 1LL<<62；不修改图，时间 O(n+m)。
// BFS（Breadth-First Search）：广度优先搜索；0-1 BFS 用双端队列处理 0/1 边权。
vector<i64> bfs01(const vector<vector<pair<int, int>>>& g, int s) {
    const i64 INF = (1LL << 62);
    vector<i64> dist(g.size(), INF);
    // done[u]：顶点 u 是否已经确定最短距离并展开，防止重复处理。
    vector<char> done(g.size());
    deque<int> q;
    dist[s] = 0;
    q.push_front(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop_front();
        if (done[u]) continue;
        done[u] = 1;
        for (auto [v, w] : g[u]) {
            assert(w == 0 || w == 1);
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                if (w) {
                    q.push_back(v);
                }
                else {
                    q.push_front(v);
                }
            }
        }
    }
    return dist;
}
```

**调用与说明**：不可达点距离为 (1LL << 62)。无权图直接使用普通队列 BFS。

### 3.1.3 Bellman-Ford：负边与可达负环

[完整代码：3.1.3 Bellman-Ford：负边与可达负环.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.1.3%20Bellman-Ford%EF%BC%9A%E8%B4%9F%E8%BE%B9%E4%B8%8E%E5%8F%AF%E8%BE%BE%E8%B4%9F%E7%8E%AF.cpp)

**用途与条件**：允许负边，检测从 s 可达的负环。若返回 true，距离数组不再作为有效最短路结果使用。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。

**复杂度**：时间 O(nm)，空间 O(n)。

**易错点**：只检查源点可达负环。若需检查任意负环，可将所有初始距离设为 0，等价于加入超级源点。使用 i128 避免多轮松弛过早溢出。

```cpp
struct Edge {
    int u, v;
    i64 w;
};
// 在 n 个点、边列表 e 中求 s 出发的最短路，并检查可达负环；点编号 1..n。
// 返回 {有无可达负环,距离}，有负环时距离无效，不可达为 i128(1)<<120。
// 允许负权，不修改输入；时间 O(nm)，空间 O(n)。
pair<bool, vector<i128>> bellman_ford(int n, const vector<Edge>& e, int s) {
    const i128 INF = (i128(1) << 120);
    vector<i128> dist(n + 1, INF);
    dist[s] = 0;
    for (int it = 0; it < n; ++it) {
        bool changed = false;
        for (auto [u, v, w] : e) {
            if (dist[u] != INF && dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                changed = true;
            }
        }
        if (!changed) return {false, dist};
        if (it == n - 1) return {true, dist};
    }
    return {false, dist};
}
```

**调用与说明**：auto [negative,dist]=bellman_ford(n,edges,s); 仅当 negative==false 时使用 dist；不可达为 i128(1)<<120。

## 3.2 拓扑排序与 DAG 动态规划

[完整代码：3.2 拓扑排序与 DAG 动态规划.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.2%20%E6%8B%93%E6%89%91%E6%8E%92%E5%BA%8F%E4%B8%8E%20DAG%20%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92.cpp)

**用途与条件**：Kahn 算法返回有向图拓扑序。返回长度小于 n 说明存在有向环。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。

**复杂度**：时间 O(n+m)，空间 O(n)。

**易错点**：拓扑序不一定唯一。在拓扑序中按边转移即可做 DAG DP；最长路初始化要区分不可达与 0。

```cpp
// 对 g[1..n] 做拓扑排序，返回无占位的顶点顺序列表；不修改图。
// 返回长度不足 n 表示存在有向环，此时列表并非全图拓扑序；时间 O(n+m)。
// DAG（Directed Acyclic Graph）：有向无环图。
// DP（Dynamic Programming）：动态规划，可按 DAG 的拓扑序转移。
vector<int> topo_sort(const vector<vector<int>>& g) {
    int n = (int)g.size() - 1;
    // deg[u]：尚未删除的入边数量；ans：依次取出的拓扑序顶点。
    vector<int> deg(n + 1), ans;
    queue<int> q;
    for (auto& es : g) {
        for (int v : es) ++deg[v];
    }
    for (int i = 1; i <= n; ++i) {
        if (!deg[i]) q.push(i);
    }
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ans.push_back(u);
        for (int v : g[u]) {
            if (--deg[v] == 0) q.push(v);
        }
    }
    return ans;
}
```

**调用与说明**：auto ord=topo_sort(g); if(ord.size()!=g.size()-1) 则不是 DAG。ord 为无占位的顶点顺序列表。

## 3.3 Kruskal：最小生成森林

[完整代码：3.3 Kruskal：最小生成森林.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.3%20Kruskal%EF%BC%9A%E6%9C%80%E5%B0%8F%E7%94%9F%E6%88%90%E6%A3%AE%E6%9E%97.cpp)

**用途与条件**：无向带权图，可含负权、重边、自环。返回最小生成森林权值与选中边数。顶点编号为 1..n；Edge 保存起点、终点和 i64 边权，边列表从 0 下标开始。依赖 2.1 并查集，独立代码中已展开。

**复杂度**：时间 O(m log m)，空间 O(n+m)。

**易错点**：选中边数为 n-1 才是整张图的一棵生成树。权值之和须在 i64 范围内。不要把断开图的森林权值误当作 MST。

**依赖**：[查看 2.1「并查集」](02_%E6%95%B0%E6%8D%AE%E7%BB%93%E6%9E%84.md#algorithm-dsu)；完整代码已展开依赖，可单独使用。

```cpp
struct Edge {
    int u, v;
    i64 w;
};
// 使用 2.1 并查集的 init、find、merge；独立文件中已展开依赖。
// 求 n 个顶点的最小生成森林，es 为无向边列表，可有负权、重边、自环。
// 返回 {总权值,选中边数}；选中 n-1 条边才表示整图连通，权值和须在 i64 范围内。
// 要求 n>=1，顶点为 1..n；不修改调用者的 es，会重置全局并查集。
// 时间 O(n + m log(m+1))，空间 O(n+m)。
pair<i64, int> kruskal(int n, vector<Edge> es) {
    init(n);
    // 按边权从小到大比较两条边，供 Kruskal 依次尝试选边。
    sort(es.begin(), es.end(), [](const Edge& a, const Edge& b) { return a.w < b.w; });
    int num = n;
    i64 result = 0;
    for (int i = 0; i < (int)es.size(); ++i) {
        if (!merge(es[i].u, es[i].v)) continue;
        --num;
        result += es[i].w;
        if (num == 1) break;
    }
    return {result, n - num};
}
```

**调用与说明**：auto [weight,used]=kruskal(n,edges); 检查 used==n-1。

### 3.4.1 迭代 Kosaraju

[完整代码：3.4.1 迭代 Kosaraju.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.4.1%20%E8%BF%AD%E4%BB%A3%20Kosaraju.cpp)

**用途与条件**：迭代 Kosaraju 求有向图强连通分量；顶点 1..n，使用原图和反图，两轮遍历，无递归调用栈。comp 为 0..cc-1 的分量编号。

**复杂度**：时间 O(n+m)，总空间 O(n+m)，保存原图和反图。

**易错点**：跨分量边 u→v 满足 comp[u]<comp[v]；接口 add_edge、build、comp、cc。与 Tarjan 编号方向不同。

```cpp
// SCC（Strongly Connected Component）：强连通分量；此处采用 Kosaraju 算法。
// DFS（Depth-First Search）：深度优先搜索，本实现用显式栈模拟。
struct SCC {
    // cc：强连通分量数量，已分配的分量编号为 0..cc-1。
    int n, cc = 0;
    // g：原图；rg（reverse graph）：将全部有向边反转后的图。
    vector<vector<int>> g, rg;
    // comp[u]：顶点 u 所属分量的编号，-1 表示尚未分配。
    vector<int> comp;
    // 初始化编号 1..n 的有向图和反图；时间和空间 O(n)。
    SCC(int n) : n(n), g(n + 1), rg(n + 1) {}
    // 添加有向边 u→v，同时在反图加入 v→u；要求端点在 1..n，均摊 O(1)。
    void add_edge(int u, int v) {
        g[u].push_back(v);
        rg[v].push_back(u);
    }
    // 用迭代 Kosaraju 重算强连通分量，将数量写入 cc、编号写入 comp[1..n]。
    // 编号为 0..cc-1，跨分量边 u→v 满足 comp[u]<comp[v]；可加边后重新调用。
    // 时间 O(n+m)，无需递归调用栈。
    void build() {
        cc = 0;
        vector<char> vis(n + 1);
        // order：第一遍 DFS 的完成顺序，反转后用于第二遍遍历。
        vector<int> order;
        for (int s = 1; s <= n; ++s) {
            if (!vis[s]) {
                // st：模拟递归的栈；每项保存顶点和下一条待处理邻边的下标。
                vector<pair<int, int>> st{{s, 0}};
                vis[s] = 1;
                while (!st.empty()) {
                    int u = st.back().first;
                    int& i = st.back().second;
                    if (i == (int)g[u].size()) {
                        order.push_back(u);
                        st.pop_back();
                    }
                    else {
                        int v = g[u][i++];
                        if (!vis[v]) {
                            vis[v] = 1;
                            st.push_back({v, 0});
                        }
                    }
                }
            }
        }
        comp.assign(n + 1, -1);
        reverse(order.begin(), order.end());
        for (int s : order) {
            if (comp[s] == -1) {
                vector<int> st{s};
                comp[s] = cc;
                while (!st.empty()) {
                    int u = st.back();
                    st.pop_back();
                    for (int v : rg[u]) {
                        if (comp[v] == -1) {
                            comp[v] = cc;
                            st.push_back(v);
                        }
                    }
                }
                ++cc;
            }
        }
    }
};
```

**调用与说明**：SCC s(n); s.add_edge(u,v); s.build(); s.comp[u] 为分量编号，s.cc 为分量数量。

### 3.4.2 递归 Tarjan

[完整代码：3.4.2 递归 Tarjan.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.4.2%20%E9%80%92%E5%BD%92%20Tarjan.cpp)

**用途与条件**：递归 Tarjan 求有向图强连通分量；顶点 1..n，使用 dfn、low 和节点栈，不需要反图。comp 为 0..cc-1 的分量编号。

**复杂度**：时间 O(n+m)，总空间 O(n+m)，递归深度最坏 O(n)。

**易错点**：跨分量边 u→v 满足 comp[u]>comp[v]；长链可能使递归栈溢出。缩点后重边是否去重按题意决定。

```cpp
// SCC（Strongly Connected Component）：强连通分量；此处采用 Tarjan 算法。
// DFS（Depth-First Search）：深度优先搜索。
struct TarjanSCC {
    int n, cc = 0, timer = 0;
    vector<vector<int>> g;
    // dfn[u]：首次访问时间戳，0 表示未访问；low[u]：按 Tarjan 转移维护的可达最小时间戳。
    // st：尚未归属分量的顶点栈；comp[u]：所属强连通分量编号。
    // cc：分量数量；timer：DFS 时间戳计数器。
    vector<int> dfn, low, st, comp;
    // in_stack[u]：u 是否仍在分量栈中；已出栈顶点不能用于降低 low。
    vector<char> in_stack;
    // 初始化编号 1..n 的有向图；遍历数组在 build 中初始化。
    TarjanSCC(int n) : n(n), g(n + 1) {}
    // 添加有向边 u→v，端点需在 1..n；均摊 O(1)。
    void add_edge(int u, int v) {
        g[u].push_back(v);
    }
    // 内部 Tarjan 遍历：访问尚未访问的 u，维护 dfn、low 和栈，并弹出完整强连通分量。
    // 由 build 初始化状态后调用，可能递归至 O(n) 深度。
    void dfs(int u) {
        dfn[u] = low[u] = ++timer;
        st.push_back(u);
        in_stack[u] = 1;
        for (int v : g[u]) {
            if (!dfn[v]) {
                dfs(v);
                low[u] = min(low[u], low[v]);
            }
            else if (in_stack[v]) {
                // 只有仍在分量栈中的顶点才能用于降低 low[u]，避免合并已完成的分量。
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (low[u] == dfn[u]) {
            while (true) {
                int v = st.back();
                st.pop_back();
                in_stack[v] = 0;
                comp[v] = cc;
                if (v == u) break;
            }
            ++cc;
        }
    }
    // 清空遍历状态并重算全部强连通分量，写入 comp[1..n] 与数量 cc。
    // 编号为 0..cc-1，跨分量边 u→v 满足 comp[u]>comp[v]；时间 O(n+m)。
    void build() {
        cc = timer = 0;
        st.clear();
        dfn.assign(n + 1, 0);
        low.assign(n + 1, 0);
        comp.assign(n + 1, -1);
        in_stack.assign(n + 1, 0);
        for (int u = 1; u <= n; ++u) {
            if (!dfn[u]) dfs(u);
        }
    }
};
```

**调用与说明**：TarjanSCC s(n); s.add_edge(u,v); s.build(); 用 s.comp[u]==s.comp[v] 判断两点是否属于同一 SCC；s.cc 是分量数。修改图后可以重新 build()。



#### 两种实现的区别

| 对比项 | 迭代 Kosaraju（SCC） | 递归 Tarjan（TarjanSCC） |
|---|---|---|
| 核心思路 | 原图求完成顺序，再按完成顺序的逆序遍历反图 | 一轮 DFS，用 dfn、low 和待归属节点栈识别 SCC |
| 遍历 | 两轮遍历，每轮可启动多次 DFS | 一轮遍历，每个未访问起点启动 DFS |
| 反图 | 需要；额外保存 m 条反向邻接记录 | 不需要 |
| 时间 / 总空间 | O(n+m) / O(n+m) | O(n+m) / O(n+m) |
| 栈 | 显式栈，无递归调用栈风险 | 节点栈加递归调用栈；长链递归深度可达 n |
| 本版分量编号 | 跨分量边 u→v 满足 comp[u]<comp[v] | 跨分量边 u→v 满足 comp[u]>comp[v] |
| 选用场景 | 图很深、希望避免递归时可直接采用 | 希望省去反图且递归深度可控时可采用 |

两种算法得到相同的分组，但编号不必相同，也不保证两组编号逐项互为逆序；无依赖关系的分量顺序可以不同。例如图中只有边 1→2 时，本版 Kosaraju 得到 comp[1..2]={0,1}，Tarjan 得到 comp[1..2]={1,0}。编号方向来自这里的具体实现，不应仅凭算法名称推断其他模板的编号规则。

#### Tarjan 中 dfn、low 与栈的含义

- `dfn[u]`：u 第一次被访问的时间戳，从 1 开始；0 表示未访问。
- `low[u]`：通过 DFS 子树及指向仍在栈中节点的边，能够追溯到的最小时间戳。
- `st` / `in_stack`：记录已访问但尚未归入某个 SCC 的节点，不等同于递归调用栈。
- 若 v 未访问，先递归再用 `low[v]` 更新；若 v 已访问且仍在栈中，用 `dfn[v]` 更新；若 v 已出栈，则忽略这条边对 low 的影响。
- 当 `low[u]==dfn[u]` 时，从栈顶弹出直到 u，这些点恰好组成一个 SCC。有向图 SCC 不使用无向图“跳过父边”的写法。

#### 与下一节 2-SAT 的配合

下一节默认保留 `SCC`（Kosaraju），赋值为 `value[i] = comp[2*i-1] < comp[2*i]`。

若换成本节 `TarjanSCC`，应同时做两处修改：成员 `SCC s` 改成 `TarjanSCC s`，赋值比较改成 `value[i] = comp[2*i-1] > comp[2*i]`。无解判定 `comp[2*i-1]==comp[2*i]` 保持不变。使用独立算法文件时，成员可直接写 `TarjanSCC s`；其完整代码位于 `代码/03_图论与树/3.4.2 递归 Tarjan.cpp`；Kosaraju 位于 `代码/03_图论与树/3.4.1 迭代 Kosaraju.cpp`，两种方法分别存放。

## 3.5 2-SAT：布尔约束可满足性

[完整代码：3.5 2-SAT：布尔约束可满足性.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.5%202-SAT%EF%BC%9A%E5%B8%83%E5%B0%94%E7%BA%A6%E6%9D%9F%E5%8F%AF%E6%BB%A1%E8%B6%B3%E6%80%A7.cpp)

**用途与条件**：变量编号 1..n，字面量 node(i,v)=2*i-1+v：false 为 2*i-1，true 为 2*i。默认依赖 Kosaraju SCC，clause(a,av,b,bv) 添加 (a==av) 或 (b==bv)。

**复杂度**：n 个变量、m 个子句：时间和空间 O(n+m)。

**易错点**：赋值方向依赖 SCC 编号顺序：默认 Kosaraju 用 <；若成员改为上一节 TarjanSCC，必须同时把赋值比较改为 >。强制 x=v 使用 clause(x,v,x,v)。

**依赖**：[查看 3.4.1「迭代 Kosaraju」](#algorithm-scc)；完整代码已展开依赖，可单独使用。

```cpp
// Dependency: SCC from the previous entry.
// 2-SAT（2-Satisfiability）：每个子句至多包含两个文字的布尔可满足性问题。
struct TwoSAT {
    int n;
    SCC s;
    // value[i]：求解成功后第 i 个布尔变量的取值，0 为假、1 为真。
    vector<int> value;
    // 创建 n 个布尔变量的蕴含图，变量编号 1..n，每个变量对应两个图节点。
    TwoSAT(int n) : n(n), s(2 * n) {}
    // 加入子句 (变量 a 等于 av) 或 (变量 b 等于 bv)，转成两条蕴含边。
    // 变量编号为 1..n；clause(x,v,x,v) 可强制 x=v，均摊 O(1)。
    void clause(int a, bool av, int b, bool bv) {
        int x = 2 * a - 1 + av, y = 2 * b - 1 + bv;
        s.add_edge((x % 2 ? x + 1 : x - 1), y);
        s.add_edge((y % 2 ? y + 1 : y - 1), x);
    }
    // 判断全部子句是否可同时满足；可满足返回 true，并把一组赋值写入 value[1..n]。
    // 返回 false 时不能使用 value 作为解；此处赋值比较配合 Kosaraju 编号，时间 O(n+m)。
    bool solve() {
        s.build();
        value.resize(n + 1);
        for (int i = 1; i <= n; ++i) {
            if (s.comp[2 * i - 1] == s.comp[2 * i]) return false;
            value[i] = s.comp[2 * i - 1] < s.comp[2 * i];
        }
        return true;
    }
};
```

**调用与说明**：TwoSAT t(2); t.clause(1,true,2,false); 若 t.solve() 为 true，t.value[1..n] 给出一组合法解。

## 3.6 无向图割点与桥

[完整代码：3.6 无向图割点与桥.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.6%20%E6%97%A0%E5%90%91%E5%9B%BE%E5%89%B2%E7%82%B9%E4%B8%8E%E6%A1%A5.cpp)

**用途与条件**：Tarjan low-link 求割点、桥，支持重边。每条无向边分配唯一 id，两个方向共享该 id。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。 边 id 使用互不相同的非负整数，返回 bridges 是无占位的 id 列表。

**复杂度**：时间 O(n+m)，空间 O(n+m)。

**易错点**：跳过父边 id 而非父顶点，否则重边会出错。桥条件 low[v]>dfn[u]；非根割点条件 low[v]≥dfn[u]。递归深度可达 n。

```cpp
struct LowLink {
    int n, timer = 0;
    vector<vector<pair<int, int>>> g;
    // DFS（Depth-First Search）：深度优先搜索。
    // dfn[u]：首次访问时间戳；low[u]：从子树经树边及至多一条返祖边可达的最小时间戳。
    // bridges：桥的边编号列表；timer：访问时间戳计数器。
    vector<int> dfn, low, bridges;
    // cut[u]：顶点 u 是否为割点。
    vector<char> cut;
    // 创建 n 个顶点的无向图，初始化访问时间、low 值和割点标记；点编号为 1..n。
    LowLink(int n) : n(n), g(n + 1), dfn(n + 1), low(n + 1), cut(n + 1) {}
    // 添加无向边 u-v，两个方向使用同一 id；每条物理边需有独立非负 id，以支持重边。
    void add_edge(int u, int v, int id) {
        g[u].push_back({v, id});
        g[v].push_back({u, id});
    }
    // 内部割点/桥搜索：从未访问顶点 u 出发，pe 为父边编号，根使用 -1。
    // 更新 low、cut 和 bridges，按父边 id 跳过反向边；递归深度最多 O(n)。
    void dfs(int u, int pe) {
        dfn[u] = low[u] = ++timer;
        int child = 0;
        for (auto [v, id] : g[u]) {
            if (id == pe) continue;
            if (!dfn[v]) {
                ++child;
                dfs(v, id);
                low[u] = min(low[u], low[v]);
                if (low[v] > dfn[u]) {
                    bridges.push_back(id);
                }
                if (pe != -1 && low[v] >= dfn[u]) {
                    cut[u] = 1;
                }
            }
            else {
                low[u] = min(low[u], dfn[v]);
            }
        }
        if (pe == -1 && child > 1) {
            cut[u] = 1;
        }
    }
    // 遍历所有连通块，写入割点标记 cut[1..n] 和桥的边编号列表 bridges，时间 O(n+m)。
    // 应在全部边添加完后调用一次；本实现不清空旧状态，修改图后需重建对象。
    void build() {
        for (int i = 1; i <= n; ++i) {
            if (!dfn[i]) dfs(i, -1);
        }
    }
};
```

**调用与说明**：对象建完边后调用一次 build()。删去所有桥后求连通块可得边双连通分量；点双连通分量还需维护边栈，不能直接套此结论。

## 3.7 树链剖分、LCA 与子树区间

[完整代码：3.7 树链剖分、LCA 与子树区间.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.7%20%E6%A0%91%E9%93%BE%E5%89%96%E5%88%86%E3%80%81LCA%20%E4%B8%8E%E5%AD%90%E6%A0%91%E5%8C%BA%E9%97%B4.cpp)

**用途与条件**：输入 g[1..n] 为连通无向树，默认根 1。迭代预处理生成 1 下标 dfs 序。path(u,v,f) 将点路径拆成若干闭区间 [l,r]。

**复杂度**：预处理 O(n)；LCA O(log n)，路径拆分 O(log n) 段；结合线段树查询为 O(log² n)。

**易错点**：子树为 [pos[u],pos[u]+sz[u]-1]。内部 ord、栈是无占位列表。path 各段无方向保证，只适合交换运算；路径字符串需单独处理方向。

```cpp
// HLD（Heavy-Light Decomposition）：树链剖分。
// DFS（Depth-First Search）：深度优先搜索；DFS 序使子树对应连续区间。
struct HLD {
    int n;
    vector<vector<int>> g;
    // father[u]：父节点，根的父节点是自身；dep（depth）：深度，根为 0。
    // sz（size）：子树大小，包含自身；heavy[u]：重儿子，-1 表示没有。
    // head[u]：所在重链的链头；pos[u]：从 1 开始的 DFS 序编号。
    // rev[i]：DFS 序编号为 i 的顶点，rev[pos[u]] = u。
    vector<int> father, dep, sz, heavy, head, pos, rev;
    // 以 root 为根对非空连通无向树 g[1..n] 做迭代树链剖分，构造父亲、深度和 dfs 序。
    // pos/rev 使用 1 下标，子树区间为 [pos[u],pos[u]+sz[u]-1]；时间和空间 O(n)。
    HLD(vector<vector<int>> g, int root = 1)
        : n((int)g.size() - 1), g(move(g)), father(n + 1, -1), dep(n + 1), sz(n + 1, 1),
          heavy(n + 1, -1), head(n + 1), pos(n + 1), rev(n + 1) {
        // ord（order）：父节点先于子节点的遍历顺序，逆序处理即可汇总子树大小。
        vector<int> ord{root};
        father[root] = root;
        for (int i = 0; i < n; ++i) {
            int u = ord[i];
            for (int v : this->g[u]) {
                if (v != father[u]) {
                    father[v] = u;
                    dep[v] = dep[u] + 1;
                    ord.push_back(v);
                }
            }
        }
        for (int i = n - 1; i > 0; --i) {
            int u = ord[i], p = father[u];
            sz[p] += sz[u];
            if (heavy[p] == -1 || sz[u] > sz[heavy[p]]) {
                heavy[p] = u;
            }
        }
        int timer = 1;
        vector<pair<int, int>> st{{root, root}};
        while (!st.empty()) {
            auto [u, h] = st.back();
            st.pop_back();
            for (; u != -1; u = heavy[u]) {
                head[u] = h;
                pos[u] = timer;
                rev[timer++] = u;
                for (int v : this->g[u]) {
                    if (v != father[u] && v != heavy[u]) {
                        st.push_back({v, v});
                    }
                }
            }
        }
    }
    // 返回树上顶点 u、v 的最近公共祖先，要求顶点有效且已完成构造；时间 O(log n)。
    // LCA（Lowest Common Ancestor）：最近公共祖先。
    int lca(int u, int v) {
        while (head[u] != head[v]) {
            if (dep[head[u]] < dep[head[v]]) swap(u, v);
            u = father[head[u]];
        }
        return dep[u] < dep[v] ? u : v;
    }
    // 将 u 到 v 的点路径拆成若干 dfs 序闭区间，逐段调用 f(l,r)，包含两端与 LCA。
    // 共 O(log n) 段，但段间顺序和方向无保证；适合求和等可交换运算。
    template <class F>
    void path(int u, int v, F f) {
        while (head[u] != head[v]) {
            if (dep[head[u]] < dep[head[v]]) swap(u, v);
            f(pos[head[u]], pos[u]);
            u = father[head[u]];
        }
        if (pos[u] > pos[v]) swap(u, v);
        f(pos[u], pos[v]);
    }
};
```

**调用与说明**：先令 base[h.pos[u]]=weight[u]，用 base 建线段树。h.path(u,v,[&](int l,int r){ ans+=seg.query(l,r); }); 边权放在较深端点时，最后一段要排除 LCA。

## 3.8 虚树：关键点及其 LCA

[完整代码：3.8 虚树：关键点及其 LCA.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.8%20%E8%99%9A%E6%A0%91%EF%BC%9A%E5%85%B3%E9%94%AE%E7%82%B9%E5%8F%8A%E5%85%B6%20LCA.cpp)

**用途与条件**：依赖 HLD。将关键点按 dfs 序排列，加入相邻点 LCA 后建虚树。返回 {父节点,子节点} 边，编号仍是原树编号。 keys、nodes 和 edges 是无占位的列表（容器位置从 0 开始）；其中保存的原树顶点编号为 1..n。

**复杂度**：k 个关键点：O(k log k+k log n)，空间 O(k)；虚树节点不超过 2k-1。

**易错点**：虚边权可以取深度差或根距离差。只有一个关键点时边集为空但节点仍存在。查询间不要 O(n) 清空全部原树数组。

**依赖**：[查看 3.7「树链剖分、LCA 与子树区间」](#algorithm-hld)；完整代码已展开依赖，可单独使用。

```cpp
// Dependency: HLD.
// 根据已预处理的 HLD 和关键点列表 v 构造虚树，自动补充必要 LCA 并去重。
// 返回 {节点列表,父到子的虚边列表}，均保存原树的 1 下标编号；空关键点返回空结果。
// 列表不带占位，非空时首节点为虚树根；k 个关键点耗时 O(k log k+k log n)。
// LCA（Lowest Common Ancestor）：最近公共祖先；补齐相邻关键点的 LCA 以连接虚树。
pair<vector<int>, vector<pair<int, int>>> virtual_tree(HLD& h, vector<int> v) {
    if (v.empty()) return {{}, {}};
    // 按原树 dfs 序比较顶点 a、b，保证关键点和补入的 LCA 按树上遍历顺序排列。
    auto cmp = [&](int a, int b) { return h.pos[a] < h.pos[b]; };
    sort(v.begin(), v.end(), cmp);
    v.erase(unique(v.begin(), v.end()), v.end());
    int k = v.size();
    for (int i = 1; i < k; ++i) {
        v.push_back(h.lca(v[i - 1], v[i]));
    }
    sort(v.begin(), v.end(), cmp);
    v.erase(unique(v.begin(), v.end()), v.end());
    // st：当前虚树构造路径上的祖先栈，按 DFS 序处理节点。
    vector<int> st;
    vector<pair<int, int>> edges;
    for (int u : v) {
        while (!st.empty() &&
               !(h.pos[st.back()] <= h.pos[u] && h.pos[u] < h.pos[st.back()] + h.sz[st.back()])) {
            st.pop_back();
        }
        if (!st.empty()) {
            edges.push_back({st.back(), u});
        }
        st.push_back(u);
    }
    return {v, edges};
}
```

**调用与说明**：auto [nodes,edges]=virtual_tree(h,keys); nodes.front() 是非空虚树的根。

## 3.9 二分图最大匹配：匈牙利算法（DFS 增广路）

[完整代码：3.9 二分图最大匹配：匈牙利算法（DFS 增广路）.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.9%20%E4%BA%8C%E5%88%86%E5%9B%BE%E6%9C%80%E5%A4%A7%E5%8C%B9%E9%85%8D%EF%BC%9A%E5%8C%88%E7%89%99%E5%88%A9%E7%AE%97%E6%B3%95%EF%BC%88DFS%20%E5%A2%9E%E5%B9%BF%E8%B7%AF%EF%BC%89.cpp)

**用途与条件**：使用 DFS 寻找增广路求无权二分图最大匹配，也称 Kuhn 算法，国内竞赛中通常称为匈牙利算法。左部 nL 个点、右部 nR 个点；g[u] 只保存从左到右的边。适合中等规模二分图。左右两侧各自从 1 开始编号，g 分配 nL+1 行，第 0 行不使用。

**复杂度**：时间 O(nL·m)，空间 O(nL+nR+m)。大图优先考虑 Hopcroft-Karp 或 Dinic。

**易错点**：左右两侧独立编号。每次寻找增广路都需要新的访问标记。最大匹配不是一般图匹配，也不是最大权匹配。

```cpp
// Kuhn 算法（以 Harold W. Kuhn 命名）：国内竞赛中通常称为匈牙利算法。
// 使用 DFS（Depth-First Search，深度优先搜索）寻找增广路，求无权二分图最大匹配。
struct BipartiteMatch {
    int nL, nR, timer = 0;
    vector<vector<int>> g;
    // mr[v]：右侧顶点 v 匹配的左侧顶点，-1 表示未匹配。
    // seen[v]：右侧顶点最近被搜索的轮次；timer：当前搜索轮次。
    // nL、nR：左右两侧的顶点数量，各自从 1 开始编号。
    vector<int> mr, seen;
    // 初始化左部 l 个点、右部 r 个点的二分图，两侧各从 1 编号；mr 初值为 -1。
    BipartiteMatch(int l, int r) : nL(l), nR(r), g(l + 1), mr(r + 1, -1), seen(r + 1) {}
    // 内部增广搜索：从左点 u 尝试找到可用右点或重排旧匹配，成功返回 true 并更新 mr。
    // 使用当前 timer 防止本轮重复访问右点，由 solve 为每轮设置新时间戳。
    bool dfs(int u) {
        for (int v : g[u]) {
            if (seen[v] != timer) {
                seen[v] = timer;
                if (mr[v] == -1 || dfs(mr[v])) {
                    mr[v] = u;
                    return true;
                }
            }
        }
        return false;
    }
    // 重置并求最大匹配，返回匹配边数，mr[v] 保存右点 v 匹配的左点，-1 表示未匹配。
    // 调用前把左到右的边放入 g；时间 O(nL*m)。
    int solve() {
        fill(mr.begin(), mr.end(), -1);
        int ans = 0;
        for (int u = 1; u <= nL; ++u) {
            ++timer;
            ans += dfs(u);
        }
        return ans;
    }
};
```

**调用与说明**：BipartiteMatch b(nL,nR); b.g[u].push_back(v); b.solve(); mr[v] 为匹配到的左点，-1 表示未匹配。

## 3.10 Dinic 最大流与最小割

[完整代码：3.10 Dinic 最大流与最小割.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.10%20Dinic%20%E6%9C%80%E5%A4%A7%E6%B5%81%E4%B8%8E%E6%9C%80%E5%B0%8F%E5%89%B2.cpp)

**用途与条件**：有向非负整数容量网络。add_edge 自动建立反向残量边。结束后从 s 沿正残量边可达的点构成最小割源侧。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。

**复杂度**：一般图时间 O(n²m)，空间 O(n+m)。

**易错点**：s 与 t 必须不同。无向容量边按建模需要添加双向有容量的边。本实现修改残量网络；再次调用返回新增流量。递归深度可达 n。

```cpp
const i64 INF = (1LL << 62);

struct Dinic {
    struct E {
        // E（edge）：残量边；v：终点；rev：反向边在 g[v] 中的下标。
        int v, rev;
        // cap（capacity）：当前剩余容量，增广时会改变。
        i64 cap;
    };
    int n;
    vector<vector<E>> g;
    // level[u]：层次图中的层数，-1 表示不可达；it[u]：当前弧的邻接表下标。
    vector<int> level, it;
    // 创建 n 个顶点的空残量网络及层次、当前弧数组，顶点编号为 1..n。
    Dinic(int n) : n(n), g(n + 1), level(n + 1), it(n + 1) {}
    // 添加容量为 c 的有向边 u→v 和容量为 0 的反向残量边；c>=0，自环直接忽略。
    void add_edge(int u, int v, i64 c) {
        if (u == v) return;
        assert(c >= 0);
        int a = g[u].size(), b = g[v].size();
        g[u].push_back({v, b, c});
        g[v].push_back({u, a, 0});
    }
    // 内部建层：沿正残量边从 s 广搜，更新 level，返回汇点 t 是否可达；时间 O(n+m)。
    // BFS（Breadth-First Search）：广度优先搜索，用于构造层次图。
    bool bfs(int s, int t) {
        fill(level.begin(), level.end(), -1);
        queue<int> q;
        level[s] = 0;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (auto e : g[u]) {
                if (e.cap > 0 && level[e.v] < 0) {
                    level[e.v] = level[u] + 1;
                    q.push(e.v);
                }
            }
        }
        return level[t] >= 0;
    }
    // 在层次图中从 u 向汇点 t 尝试推送至多 f 流量，返回实际流量并更新正反残量。
    // 使用当前弧 it 跳过已尝试边；要求先 bfs 建层并初始化 it。
    // DFS（Depth-First Search）：深度优先搜索，用于沿层次图增广。
    i64 dfs(int u, int t, i64 f) {
        if (u == t) return f;
        for (int& i = it[u]; i < (int)g[u].size(); ++i) {
            E& e = g[u][i];
            if (e.cap > 0 && level[e.v] == level[u] + 1) {
                i64 z = dfs(e.v, t, min(f, e.cap));
                if (z) {
                    e.cap -= z;
                    g[e.v][e.rev].cap += z;
                    return z;
                }
            }
        }
        return 0;
    }
    // 在当前残量网络上增加 s→t 流，返回本次新增流量，最多 limit；要求 s!=t、limit>=0。
    // 会修改残量网络，重复调用只返回新增部分；未被 limit 截断时可用残量可达点求最小割。
    i64 flow(int s, int t, i64 limit = INF) {
        assert(s != t);
        i64 ans = 0;
        while (ans < limit && bfs(s, t)) {
            fill(it.begin(), it.end(), 0);
            while (i64 f = dfs(s, t, limit - ans)) {
                ans += f;
                if (ans == limit) break;
            }
        }
        return ans;
    }
};
```

**调用与说明**：Dinic d(n); d.add_edge(u,v,c); i64 ans=d.flow(s,t); 默认最多推 INF，若流可能更大应另行调整数值设计。

## 3.11 最小费用流：逐次最短增广路

[完整代码：3.11 最小费用流：逐次最短增广路.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.11%20%E6%9C%80%E5%B0%8F%E8%B4%B9%E7%94%A8%E6%B5%81%EF%BC%9A%E9%80%90%E6%AC%A1%E6%9C%80%E7%9F%AD%E5%A2%9E%E5%B9%BF%E8%B7%AF.cpp)

**用途与条件**：允许负费用边，但初始网络不得有正容量负费用环。每轮使用 Bellman-Ford，适合作为容易检查的中小规模版本。 顶点编号从 1 开始；传入邻接表时分配 n+1 行，第 0 行不使用。

**复杂度**：若增广 A 次，时间 O(A·n·m)，空间 O(n+m)。大规模使用势能+Dijkstra 版本。

**易错点**：容量非负，s≠t。返回 {流量,费用}；费用使用 i128。调用修改残量图。模型含负费用环时本算法不适用，不会自动完成消圈。

```cpp
struct MinCostFlow {
    struct E {
        // E（edge）：残量边；v：终点；rev：反向边在 g[v] 中的下标。
        int v, rev;
        // cap（capacity）：剩余容量；cost：单位流量费用，反向边费用取反。
        i64 cap, cost;
    };
    int n;
    vector<vector<E>> g;
    // 创建 n 个顶点的空费用残量网络，顶点编号为 1..n。
    MinCostFlow(int n) : n(n), g(n + 1) {}
    // 添加容量 cap、单位费用 cost 的有向边，并建立费用取反的残量边。
    // 要求端点有效且不同、cap>=0、cost!=LLONG_MIN；允许负费用。
    void add_edge(int u, int v, i64 cap, i64 cost) {
        assert(u != v && cap >= 0 && cost != LLONG_MIN);
        int a = g[u].size(), b = g[v].size();
        g[u].push_back({v, b, cap, cost});
        g[v].push_back({u, a, 0, -cost});
    }
    // 从 s 向 t 增广至多 limit 单位流，返回 {本次流量,本次总费用}，并修改残量网络。
    // 要求 s!=t、limit>=0，初始网络不能有正容量负费用环；精确需求必须检查流量等于 limit。
    // 每轮用 Bellman-Ford，若增广 A 次，时间 O(A*n*m)，费用用 i128。
    pair<i64, i128> flow(int s, int t, i64 limit) {
        assert(s != t);
        i64 f = 0;
        i128 cost = 0, INF = i128(1) << 120;
        while (f < limit) {
            vector<i128> dist(n + 1, INF);
            // pv[v]：增广路径上 v 的前驱顶点，-1 表示尚未记录。
            // pe[v]：前驱边在 g[pv[v]] 中的下标，仅在 pv[v] 有效时使用。
            vector<int> pv(n + 1, -1), pe(n + 1, -1);
            dist[s] = 0;
            for (int z = 0; z < n - 1; ++z) {
                bool changed = false;
                for (int u = 1; u <= n; ++u) {
                    if (dist[u] != INF) {
                        for (int i = 0; i < (int)g[u].size(); ++i) {
                            auto e = g[u][i];
                            if (e.cap > 0 && dist[e.v] > dist[u] + e.cost) {
                                dist[e.v] = dist[u] + e.cost;
                                pv[e.v] = u;
                                pe[e.v] = i;
                                changed = true;
                            }
                        }
                    }
                }
                if (!changed) break;
            }
            if (pv[t] == -1) break;
            i64 add = limit - f;
            for (int v = t; v != s; v = pv[v]) {
                add = min(add, g[pv[v]][pe[v]].cap);
            }
            for (int v = t; v != s; v = pv[v]) {
                E& e = g[pv[v]][pe[v]];
                // 正向剩余容量减少，反向剩余容量增加，使后续增广可以撤回已有流量。
                e.cap -= add;
                g[v][e.rev].cap += add;
            }
            f += add;
            cost += i128(add) * dist[t];
        }
        return {f, cost};
    }
};
```

**调用与说明**：auto [f,c]=net.flow(s,t,need); 需要恰好 need 单位流时必须检查 f==need。最大费用问题可在无负环条件满足时对费用取反。

### 3.12.1 点差分（TreePointDiff）

[完整代码：3.12.1 点差分（TreePointDiff）.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.12.1%20%E7%82%B9%E5%B7%AE%E5%88%86%EF%BC%88TreePointDiff%EF%BC%89.cpp)


点差分与边差分分别提供独立类和独立代码文件，统一使用 add(u,v,val) 和 result()。两版复用手册 3.7 的 HLD 求 LCA，独立文件均已展开依赖。适合批量路径加后统一取值，不适合每次修改后立即高效查询。


**用途与条件**：输入非空连通无向树 g[1..n]，默认根为 1。批量给路径上的点加值，最后统一还原各点累计增量；包含路径两端和 LCA。

**复杂度**：借助树链剖分求 LCA：预处理 O(n)，单次路径加 O(log n)，还原 O(n)，空间 O(n)。

**易错点**：令 p=lca(u,v)，两端各加 val，p 和 p 的父亲各减 val；p 为根时不减父亲。现有 HLD 将根的父亲设为根，必须特别判断。所有中间结果需在 i64 范围内；若有初始权值，在结果上另行相加。

**依赖**：[查看 3.7「树链剖分、LCA 与子树区间」](#algorithm-hld)；完整代码已展开依赖，可单独使用。

```cpp
// 依赖手册 3.7 的 HLD（树链剖分、LCA 与子树区间），独立文件已展开。
class TreePointDiff {
private:
    HLD h;
    vector<i64> diff;

public:
    // 为非空连通无向树 g[1..n] 初始化点差分，根为 root，初始增量全为 0。
    // 要求 1<=root<=n；使用迭代预处理，时间和空间 O(n)。
    TreePointDiff(const vector<vector<int>>& g, int root = 1) : h(g, root), diff(g.size(), 0) {}

    // 将 u 到 v 路径上的所有点加 val，包含两端；时间 O(log n)。
    void add(int u, int v, i64 val) {
        assert(1 <= u && u <= h.n && 1 <= v && v <= h.n);
        int p = h.lca(u, v);
        diff[u] += val;
        diff[v] += val;
        diff[p] -= val;
        if (h.father[p] != p) {
            diff[h.father[p]] -= val;
        }
    }

    // 返回各点累计增量 ans[1..n]，ans[0]=0；时间和空间 O(n)。
    // 按 dfs 序逆序向父亲累加，不修改 diff，可重复调用并继续添加操作。
    vector<i64> result() const {
        vector<i64> ans = diff;
        for (int i = h.n; i > 1; --i) {
            int u = h.rev[i];
            ans[h.father[u]] += ans[u];
        }
        return ans;
    }
};
```

**调用与说明**：TreePointDiff tree(g); tree.add(u,v,3); auto ans=tree.result(); ans[x] 为点 x 的累计增量。u==v 时仅该点增加。

### 3.12.2 边差分（TreeEdgeDiff）

[完整代码：3.12.2 边差分（TreeEdgeDiff）.cpp](../%E4%BB%A3%E7%A0%81/03_%E5%9B%BE%E8%AE%BA%E4%B8%8E%E6%A0%91/3.12.2%20%E8%BE%B9%E5%B7%AE%E5%88%86%EF%BC%88TreeEdgeDiff%EF%BC%89.cpp)

**用途与条件**：输入非空连通无向树 g[1..n]，默认根为 1。批量给路径上的边加值，结果 ans[u] 对应父节点到 u 的边；根没有父边，其结果为 0。

**复杂度**：预处理 O(n)，单次路径加 O(log n)，还原 O(n)，空间 O(n)。

**易错点**：令 p=lca(u,v)，两端各加 val，p 减两次 val。u==v 时不修改任何边。边的结果放在较深端点，按输入边 (u,v) 输出时选择深度较大的端点。所有中间结果需在 i64 范围内；初始边权在结果上另行相加。

**依赖**：[查看 3.7「树链剖分、LCA 与子树区间」](#algorithm-hld)；完整代码已展开依赖，可单独使用。

```cpp
// 依赖手册 3.7 的 HLD（树链剖分、LCA 与子树区间），独立文件已展开。
class TreeEdgeDiff {
private:
    HLD h;
    vector<i64> diff;

public:
    // 为非空连通无向树 g[1..n] 初始化边差分，根为 root，初始增量全为 0。
    // 要求 1<=root<=n；使用迭代预处理，时间和空间 O(n)。
    TreeEdgeDiff(const vector<vector<int>>& g, int root = 1) : h(g, root), diff(g.size(), 0) {}

    // 将 u 到 v 路径上的所有边加 val；u==v 时无边被修改，时间 O(log n)。
    void add(int u, int v, i64 val) {
        assert(1 <= u && u <= h.n && 1 <= v && v <= h.n);
        int p = h.lca(u, v);
        diff[u] += val;
        diff[v] += val;
        diff[p] -= val;
        diff[p] -= val;
    }

    // 返回各边累计增量，ans[u] 对应父节点到 u 的边，根及 ans[0] 为 0。
    // 逆序向父亲累加，不修改 diff，可重复调用并继续更新；时间和空间 O(n)。
    vector<i64> result() const {
        vector<i64> ans = diff;
        for (int i = h.n; i > 1; --i) {
            int u = h.rev[i];
            ans[h.father[u]] += ans[u];
        }
        ans[h.rev[1]] = 0;
        return ans;
    }
};
```

**调用与说明**：TreeEdgeDiff tree(g); tree.add(u,v,2); auto ans=tree.result(); ans[x] 为父节点到 x 的边的累计增量。对于根为 1 的链 1—2—3，add(1,3,2) 的结果为 {0,0,2,2}。
