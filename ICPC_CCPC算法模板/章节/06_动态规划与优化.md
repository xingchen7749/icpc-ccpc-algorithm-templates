### 6.1.1 0/1 背包

[完整代码：6.1.1 0／1 背包.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.1.1%200%EF%BC%8F1%20%E8%83%8C%E5%8C%85.cpp)

**用途与条件**：每件物品最多选一次，容量倒序更新。 dp[0..W] 表示容量不超过上限的最大价值，允许不选。

**复杂度**：每件物品 O(W)。空间 O(W)。

**易错点**：物品重量必须为正；价值乘积及转移加法不能溢出；dp 初始全为 0，不表示恰好装满。

```cpp
// 将一件重量 w、价值 v 的物品加入 0/1 背包，原地更新 dp[0..W]，容量倒序。
// 要求 w>0；默认 dp 为容量不超过上限的最优值且允许不选，加法不得溢出；时间 O(W)。
// DP（Dynamic Programming）：动态规划；dp[j] 表示容量不超过 j 时可获得的最大价值。
void zero_one(vector<i64>& dp, int w, i64 v) {
    assert(w > 0);
    for (int c = (int)dp.size() - 1; c >= w; --c) {
        dp[c] = max(dp[c], dp[c - w] + v);
    }
}
```

**调用与说明**：vector<i64> dp(W+1,0); zero_one(dp,w,v); 答案为 dp[W]。

### 6.1.2 完全背包

[完整代码：6.1.2 完全背包.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.1.2%20%E5%AE%8C%E5%85%A8%E8%83%8C%E5%8C%85.cpp)

**用途与条件**：每种物品无限使用，容量正序更新。 dp[0..W] 表示容量不超过上限的最大价值，允许不选。

**复杂度**：每种物品 O(W)。空间 O(W)。

**易错点**：物品重量必须为正；价值乘积及转移加法不能溢出；dp 初始全为 0，不表示恰好装满。

```cpp
// 将可无限使用的重量 w、价值 v 的物品加入完全背包，原地更新 dp，容量正序。
// 要求 w>0，dp 使用容量 0..W；当前初始化约定为不要求恰好装满，时间 O(W)。
// DP（Dynamic Programming）：动态规划；dp[j] 表示容量不超过 j 时可获得的最大价值。
void complete(vector<i64>& dp, int w, i64 v) {
    assert(w > 0);
    for (int c = w; c < (int)dp.size(); ++c) {
        dp[c] = max(dp[c], dp[c - w] + v);
    }
}
```

**调用与说明**：vector<i64> dp(W+1,0); complete(dp,w,v); 答案为 dp[W]。

### 6.1.3 多重背包：二进制拆分

[完整代码：6.1.3 多重背包：二进制拆分.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.1.3%20%E5%A4%9A%E9%87%8D%E8%83%8C%E5%8C%85%EF%BC%9A%E4%BA%8C%E8%BF%9B%E5%88%B6%E6%8B%86%E5%88%86.cpp)

**用途与条件**：每种物品最多 count 件，二进制拆分后调用 0/1 更新。 dp[0..W] 表示容量不超过上限的最大价值，允许不选。

**复杂度**：每种物品 O(W*log(count+1))。空间 O(W)。

**易错点**：物品重量必须为正；价值乘积及转移加法不能溢出；dp 初始全为 0，不表示恰好装满。

**依赖**：[查看 6.1.1「0/1 背包」](#algorithm-knapsack)；完整代码已展开依赖，可单独使用。

```cpp
// 将最多 count 件重量 w、价值 v 的物品加入多重背包，二进制拆分后更新 dp。
// 要求 w>0、count>=0，价值乘积及转移和不溢出；时间 O(W*log(count+1))。
// DP（Dynamic Programming）：动态规划；dp[j] 表示容量不超过 j 时可获得的最大价值。
void bounded(vector<i64>& dp, int w, i64 v, int count) {
    assert(w > 0 && count >= 0);
    for (i64 k = 1; count > 0; k *= 2) {
        int take = (int)min<i64>(k, count);
        count -= take;
        i64 weight = 1LL * w * take;
        if (weight < (int)dp.size()) {
            zero_one(dp, (int)weight, v * take);
        }
    }
}
```

**调用与说明**：vector<i64> dp(W+1,0); bounded(dp,w,v,count); 答案为 dp[W]。

## 6.2 最长严格上升子序列及方案恢复

[完整代码：6.2 最长严格上升子序列及方案恢复.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.2%20%E6%9C%80%E9%95%BF%E4%B8%A5%E6%A0%BC%E4%B8%8A%E5%8D%87%E5%AD%90%E5%BA%8F%E5%88%97%E5%8F%8A%E6%96%B9%E6%A1%88%E6%81%A2%E5%A4%8D.cpp)

**用途与条件**：输入 a[1..n]，a[0] 忽略；返回最长严格上升子序列的原数组 1 下标。返回值是无占位的下标列表，内部 tail 也是无占位列表。

**复杂度**：时间 O(n log n)，空间 O(n)。

**易错点**：严格上升用 lower_bound；最长不下降改为 upper_bound。恢复的方案不保证字典序最小。

```cpp
// 返回 a[1..n] 的一条最长严格上升子序列对应的原数组下标列表，忽略 a[0]。
// 结果列表不带占位，不保证字典序最小；时间 O(n log n)，空间 O(n)。
// LIS（Longest Increasing Subsequence）：最长严格上升子序列。
vector<int> lis_indices(const vector<i64>& a) {
    // tail[k]：长度为 k+1 的严格上升子序列可取得的最小末尾值。
    vector<i64> tail;
    // at[k]：tail[k] 对应的原数组下标；prev[i]：恢复方案时 i 的前驱下标，-1 表示无前驱。
    vector<int> at, prev(a.size(), -1);
    for (int i = 1; i < (int)a.size(); ++i) {
        int k = lower_bound(tail.begin(), tail.end(), a[i]) - tail.begin();
        if (k) prev[i] = at[k - 1];
        if (k == (int)tail.size()) {
            tail.push_back(a[i]);
            at.push_back(i);
        }
        else {
            tail[k] = a[i];
            at[k] = i;
        }
    }
    vector<int> ans;
    if (at.empty()) return ans;
    for (int i = at.back(); i != -1; i = prev[i]) ans.push_back(i);
    reverse(ans.begin(), ans.end());
    return ans;
}
```

**调用与说明**：lis_indices({0,3,1,2,2,4}) 返回长度为 3 的原数组下标列表，例如 {2,4,5}，对应值 {1,2,4}。

## 6.3 最长公共子序列：滚动数组

[完整代码：6.3 最长公共子序列：滚动数组.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.3%20%E6%9C%80%E9%95%BF%E5%85%AC%E5%85%B1%E5%AD%90%E5%BA%8F%E5%88%97%EF%BC%9A%E6%BB%9A%E5%8A%A8%E6%95%B0%E7%BB%84.cpp)

**用途与条件**：返回两个字符串的 LCS 长度。状态 dp[j] 表示当前前缀与 b 的前 j 个字符的 LCS。

**复杂度**：时间 O(nm)，空间 O(m)。

**易错点**：滚动数组不能直接恢复方案。若需要恢复，可保存完整状态或采用 Hirschberg 分治。字符相等转移来自上一行上一列。

```cpp
// 返回字符串 a、b 的最长公共子序列长度，允许不连续；空串对应答案 0。
// 滚动数组不保存恢复方案所需的信息；时间 O(|a|*|b|)，空间 O(|b|)。
// LCS（Longest Common Subsequence）：最长公共子序列。
// DP（Dynamic Programming）：动态规划。
int lcs(const string& a, const string& b) {
    // dp[j]：当前已处理的 a 前缀与 b 的前 j 个字符的 LCS 长度，原地滚动更新。
    vector<int> dp(b.size() + 1);
    for (char x : a) {
        int diag = 0;
        for (int j = 1; j <= (int)b.size(); ++j) {
            int old = dp[j];
            if (x == b[j - 1]) {
                dp[j] = diag + 1;
            }
            else {
                dp[j] = max(dp[j], dp[j - 1]);
            }
            diag = old;
        }
    }
    return dp.back();
}
```

**调用与说明**：lcs("abcde","ace")==3。

## 6.4 数位 DP：相邻数字不同

[完整代码：6.4 数位 DP：相邻数字不同.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.4%20%E6%95%B0%E4%BD%8D%20DP%EF%BC%9A%E7%9B%B8%E9%82%BB%E6%95%B0%E5%AD%97%E4%B8%8D%E5%90%8C.cpp)

**用途与条件**：示例统计 [0,N] 中十进制相邻位不相等的整数，包含 0。展示 tight、前导零与记忆化的处理方式。 例外：pos 为字符串位置，从 0 开始；prev=10 是未开始哨兵。

**复杂度**：十进制位数 D：O(D·11·10) 时间，O(D·11) 空间。

**易错点**：前导零不参与相邻位比较，prev=10 表示尚未开始。只缓存非 tight 状态。区间答案 count(R)-count(L-1)，要求 L≥0。

```cpp
// 统计闭区间 [0,N] 中十进制相邻数字不同的整数个数，计入 0；N<0 返回 0。
// 前导零不参与比较；可用 count(R)-count(L-1) 求区间答案，时间与十进制位数成正比。
// DP（Dynamic Programming）：动态规划；此处按数位及上一位数字划分状态。
// DFS（Depth-First Search）：深度优先搜索，此处配合记忆化实现数位 DP。
u64 count_no_equal_adjacent(i64 N) {
    if (N < 0) return 0;
    string s = to_string(N);
    // memo[pos][prev]：不受上界约束时的补全数量；prev=10 表示尚未出现非前导零数字。
    u64 memo[20][11]{};
    bool vis[20][11]{};
    // 内部数位搜索：pos 为当前 0 下标位，prev 为上一位数字，10 表示尚未开始。
    // tight 表示前缀是否贴住上界；返回当前状态的合法补全数量，仅缓存不贴上界的状态。
    function<u64(int, int, bool)> dfs = [&](int pos, int prev, bool tight) -> u64 {
        if (pos == (int)s.size()) return 1;
        if (!tight && vis[pos][prev]) return memo[pos][prev];
        int lim = tight ? s[pos] - '0' : 9;
        u64 ans = 0;
        for (int d = 0; d <= lim; ++d) {
            int next = (prev == 10 && d == 0) ? 10 : d;
            if (prev != 10 && d == prev) continue;
            ans += dfs(pos + 1, next, tight && d == lim);
        }
        if (!tight) {
            vis[pos][prev] = true;
            memo[pos][prev] = ans;
        }
        return ans;
    };
    return dfs(0, 10, true);
}
```

**调用与说明**：count_no_equal_adjacent(20)==20，0..20 中只有 11 不满足。

## 6.5 SOS DP：子集和与超集和

[完整代码：6.5 SOS DP：子集和与超集和.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.5%20SOS%20DP%EF%BC%9A%E5%AD%90%E9%9B%86%E5%92%8C%E4%B8%8E%E8%B6%85%E9%9B%86%E5%92%8C.cpp)

**用途与条件**：对 n 位掩码计算 f[S]=Σ a[T]，其中 T 是 S 的子集。超集和使用相反方向。 例外：下标直接表示位掩码，0 是空集，不能改成从 1 开始。

**复杂度**：时间 O(n·2^n)，空间 O(2^n)。

**易错点**：n 必须足够小以容纳 2^n 状态，通常不超过 22 左右；实际以内存限制为准。容斥逆变换将 += 改成 -=。

```cpp
// 返回每个掩码 S 的子集和 Σ(T⊆S) f[T]；按值处理，不修改调用者的数组。
// 要求 0<=n<31、f.size()==2^n 且内存足够，累加不溢出；时间 O(n*2^n)。
// SOS DP（Sum Over Subsets Dynamic Programming）：子集和动态规划。
// f[mask] 初始为单个集合的值，逐位转移后为 mask 的所有子集的值之和。
vector<i64> subset_sum(vector<i64> f, int n) {
    assert(0 <= n && n < 31 && f.size() == (1ULL << n));
    for (int b = 0; b < n; ++b) {
        for (int s = 0; s < (1 << n); ++s) {
            if (s >> b & 1) {
                f[s] += f[s ^ (1 << b)];
            }
        }
    }
    return f;
}
// 返回每个掩码 S 的超集和 Σ(T⊇S) f[T]，掩码 0 表示空集。
// 要求 0<=n<31、f.size()==2^n 且内存足够，累加不溢出；时间 O(n*2^n)。
// f[mask] 初始为单个集合的值，逐位转移后为 mask 的所有超集的值之和。
vector<i64> superset_sum(vector<i64> f, int n) {
    assert(0 <= n && n < 31 && f.size() == (1ULL << n));
    for (int b = 0; b < n; ++b) {
        for (int s = 0; s < (1 << n); ++s) {
            if (!(s >> b & 1)) {
                f[s] += f[s ^ (1 << b)];
            }
        }
    }
    return f;
}
```

**调用与说明**：subset_sum({1,2,3,4},2) 返回 {1,3,4,10}。枚举 S 的非空子集：for(int T=S;T;T=(T-1)&S)。

## 6.6 树形 DP：最大权独立集

[完整代码：6.6 树形 DP：最大权独立集.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.6%20%E6%A0%91%E5%BD%A2%20DP%EF%BC%9A%E6%9C%80%E5%A4%A7%E6%9D%83%E7%8B%AC%E7%AB%8B%E9%9B%86.cpp)

**用途与条件**：在树上选若干互不相邻节点，使权值和最大。允许空集；输入连通无向树。使用迭代后序避免深递归。 邻接表 g 和权值 w 均为 n+1 个位置，使用 1..n；内部后序列表 ord 从 0 存放。

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：dp[u][0] 表示不选 u，dp[u][1] 表示选 u。父亲选中时子节点不能选；全为负权时答案为 0。

```cpp
// 返回连通无向树的最大权独立集权值和，允许不选任何点；全负权时返回 0。
// g 和 w 均使用 1..n，0 号占位，要求权值和不溢出；迭代遍历耗时、空间均为 O(n)。
// DP（Dynamic Programming）：动态规划；此处在树上按子树合并状态。
i64 tree_independent_set(const vector<vector<int>>& g, const vector<i64>& w) {
    int n = (int)g.size() - 1;
    if (!n) return 0;
    vector<int> father(n + 1, -1), ord{1};
    father[1] = 1;
    for (int i = 0; i < n; ++i) {
        for (int v : g[ord[i]]) {
            if (v != father[ord[i]]) {
                father[v] = ord[i];
                ord.push_back(v);
            }
        }
    }
    // dp[u][0]：不选 u 的子树最大权值；dp[u][1]：选 u 的子树最大权值。
    vector<array<i64, 2>> dp(n + 1);
    for (int i = n - 1; i >= 0; --i) {
        int u = ord[i];
        dp[u][1] = w[u];
        for (int v : g[u]) {
            if (v != father[u]) {
                dp[u][0] += max(dp[v][0], dp[v][1]);
                dp[u][1] += dp[v][0];
            }
        }
    }
    return max(dp[1][0], dp[1][1]);
}
```

**调用与说明**：三点链权值 {2,3,2}，答案为 4，选择两端。

## 6.7 李超线段树：直线最小值与 DP 优化

[完整代码：6.7 李超线段树：直线最小值与 DP 优化.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.7%20%E6%9D%8E%E8%B6%85%E7%BA%BF%E6%AE%B5%E6%A0%91%EF%BC%9A%E7%9B%B4%E7%BA%BF%E6%9C%80%E5%B0%8F%E5%80%BC%E4%B8%8E%20DP%20%E4%BC%98%E5%8C%96.cpp)

**用途与条件**：离线收集所有将要查询的 x 坐标，支持任意斜率直线 y=kx+b 插入和单点最小值查询；适合 dp[i]=min_j(k[j]x[i]+b[j])。 构造参数 x 使用 1 下标，x[0] 忽略；内部坐标压缩缓冲区使用 0 下标。

**复杂度**：坐标数 M：每次插入与查询 O(log M)，空间 O(M)。

**易错点**：查询 x 必须在构造坐标中。直线值用 i128，要求实际值绝对值<2^126。无直线时返回 INF。本版本插入整条直线，不是线段。

```cpp
// DP（Dynamic Programming）：动态规划；李超树可维护直线形式的转移最小值。
struct LiChao {
    struct Line {
        i64 k = 0, b = 0;
        // 计算当前直线在 x 处的 y=k*x+b，使用 i128 中间量；有效值绝对值须小于 2^126。
        i128 eval(i64 x) const { return i128(k) * x + b; }
    };
    const i128 INF = i128(1) << 126;
    // xs：排序去重后的所有查询横坐标，下标从 0 开始。
    vector<i64> xs;
    // t[p]：线段树节点保存的候选直线；has[p] 表示该节点是否已有直线。
    vector<Line> t;
    vector<char> has;
    // 收集全部将被查询的横坐标 x[1..m]，忽略 x[0]，排序去重后建立空李超树。
    // 至少需要一个有效坐标；初始化时间 O(m log m)，存储 O(m)。
    LiChao(vector<i64> x) : xs(move(x)) {
        assert(!xs.empty());
        xs.erase(xs.begin());
        sort(xs.begin(), xs.end());
        xs.erase(unique(xs.begin(), xs.end()), xs.end());
        assert(!xs.empty());
        t.resize(xs.size() * 4);
        has.resize(xs.size() * 4);
    }
    // 向李超树插入整条直线 v={k,b}，维护已收集坐标处的最小值；时间 O(log m)。
    void add(Line v) {
        add(1, 0, xs.size(), v);
    }
    // 内部递归插入：节点 p 覆盖压缩坐标下标区间 [l,r)，其中下标从 0 开始。
    // 保留在中点更优的直线，再递归处理另一条线可能更优的一侧。
    void add(int p, int l, int r, Line v) {
        if (!has[p]) {
            has[p] = 1;
            t[p] = v;
            return;
        }
        int m = (l + r) / 2;
        bool left = v.eval(xs[l]) < t[p].eval(xs[l]);
        bool mid = v.eval(xs[m]) < t[p].eval(xs[m]);
        if (mid) swap(t[p], v);
        if (r - l == 1) return;
        if (left != mid) {
            add(p * 2, l, m, v);
        }
        else {
            add(p * 2 + 1, m, r, v);
        }
    }
    // 返回所有已插入直线在横坐标 x 处的最小值；x 必须在构造时收集的坐标中。
    // 尚未插入直线时返回 INF，时间 O(log m)，不修改树。
    i128 query(i64 x) {
        int idx = lower_bound(xs.begin(), xs.end(), x) - xs.begin();
        assert(idx < (int)xs.size() && xs[idx] == x);
        int p = 1, l = 0, r = xs.size();
        i128 ans = INF;
        while (true) {
            if (has[p]) {
                ans = min(ans, t[p].eval(x));
            }
            if (r - l == 1) break;
            int m = (l + r) / 2;
            if (idx < m) {
                p *= 2;
                r = m;
            }
            else {
                p = p * 2 + 1;
                l = m;
            }
        }
        return ans;
    }
};
```

**调用与说明**：LiChao lc({0,0,1,2}); lc.add({2,3}); lc.add({-1,5}); lc.query(2)==3；首个 0 是占位，第二个 0 是真实坐标。

## 6.8 分治优化 DP

[完整代码：6.8 分治优化 DP.cpp](../%E4%BB%A3%E7%A0%81/06_%E5%8A%A8%E6%80%81%E8%A7%84%E5%88%92%E4%B8%8E%E4%BC%98%E5%8C%96/6.8%20%E5%88%86%E6%B2%BB%E4%BC%98%E5%8C%96%20DP.cpp)

**用途与条件**：计算 cur[mid]=min_{0≤j<mid}(prev[j]+cost(j,mid))。适用于每行最优决策位置随 mid 单调不减的转移。cost 为 O(1)。 输入普通数组应采用 1 下标；DP 下标是前缀长度，prev[0] 表示空前缀。cost(j,i) 对应末组原数组闭区间 [j+1,i]。

**复杂度**：每层 O(n log n)，空间 O(n+log n)。

**易错点**：必须先证明决策单调性，常由四边形不等式导出。不能对任意 DP 使用。prev 不可达为 INF；有效加法结果须严格落在 (-INF,INF)。

```cpp
const i64 INF = (1LL << 62);

// 计算一层 cur[i]=min(0<=j<i){prev[j]+cost(j,i)}，返回 cur[0..n]，cur[0]=INF。
// prev 的下标是前缀长度，cost(j,i) 对应原数组 [j+1,i]；要求最优决策位置单调不减。
// 不可达 prev 用 INF，有限转移结果须在 (-INF,INF)；cost 为 O(1) 时耗时 O(n log n)。
template <class Cost>
// DP（Dynamic Programming）：动态规划；利用最优决策下标的单调性分治计算一层。
vector<i64> divide_dp_layer(const vector<i64>& prev, Cost cost) {
    int n = prev.size() - 1;
    // prev：上一层 DP 值；cur：正在计算的当前层 DP 值，INF 表示尚无有效转移。
    vector<i64> cur(n + 1, INF);
    // 内部决策分治：求 cur[l..r]，最优决策只在 [optL,optR] 中搜索。
    // 先计算中点最优决策，再收窄左右搜索范围；只有决策单调性成立时才正确。
    function<void(int, int, int, int)> go = [&](int l, int r, int optL, int optR) {
        if (l > r) return;
        int mid = (l + r) / 2, best = optL;
        for (int j = optL; j <= min(mid - 1, optR); ++j) {
            if (prev[j] == INF) continue;
            i128 v = i128(prev[j]) + cost(j, mid);
            if (v < cur[mid]) {
                cur[mid] = (i64)v;
                best = j;
            }
        }
        go(l, mid - 1, optL, best);
        go(mid + 1, r, best, optR);
    };
    if (n) go(1, n, 0, n - 1);
    return cur;
}
```

**调用与说明**：分组 DP 可令 prev[0]=0，其他为 INF，逐层调用。cost(j,i) 为最后一组 [j+1,i] 的代价。
