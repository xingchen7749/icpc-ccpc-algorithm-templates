## 4.1 前缀函数与 KMP 匹配

[完整代码：4.1 前缀函数与 KMP 匹配.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.1%20%E5%89%8D%E7%BC%80%E5%87%BD%E6%95%B0%E4%B8%8E%20KMP%20%E5%8C%B9%E9%85%8D.cpp)

**用途与条件**：pi[i] 为 s[0..i] 的最长真前后缀长度；匹配函数返回模式串在文本中的所有起点，允许重叠。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：时间 O(n+m)，空间 O(m+匹配数)。

**易错点**：匹配成功后跳到 pi[j-1]，不能清零，否则会漏重叠匹配。本实现约定空模式匹配文本的全部 n+1 个边界。

```cpp
// 返回前缀函数 pi，pi[i] 是 s[0..i] 的最长真前缀与后缀的公共长度。
// 字符串和返回数组均为 0 下标，空串返回空数组；时间和空间 O(|s|)。
vector<int> prefix_function(const string& s){
    vector<int>pi(s.size());
    for(int i=1;i<(int)s.size();++i){
        int j=pi[i-1];while(j&&s[i]!=s[j])j=pi[j-1];
        if(s[i]==s[j])++j;pi[i]=j;
    }
    return pi;
}
// 返回模式串 p 在 text 中所有匹配起点，使用 0 下标，允许重叠匹配。
// 空模式返回 0..text.size() 的全部边界；时间 O(|text|+|p|)，不修改输入。
vector<int> kmp(const string& text,const string& p){
    vector<int>ans;
    if(p.empty()){ans.resize(text.size()+1);iota(ans.begin(),ans.end(),0);return ans;}
    auto pi=prefix_function(p);int j=0;
    for(int i=0;i<(int)text.size();++i){
        while(j&&text[i]!=p[j])j=pi[j-1];if(text[i]==p[j])++j;
        if(j==(int)p.size()){ans.push_back(i-j+1);j=pi[j-1];}
    }
    return ans;
}
```

**调用与说明**：kmp("ababa","aba") 返回 {0,2}。若 n%(n-pi[n-1])==0，则非空串最短循环节长度为 n-pi[n-1]。

## 4.2 Z 函数

[完整代码：4.2 Z 函数.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.2%20Z%20%E5%87%BD%E6%95%B0.cpp)

**用途与条件**：z[i] 为 s 与 s.substr(i) 的最长公共前缀长度，本实现 z[0]=n。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：维护匹配区间 [l,r)。用 p+分隔符+t 匹配时，分隔符必须不在原字符集中。

```cpp
// 返回 z[i]=s 与后缀 s[i..] 的最长公共前缀长度，位置从 0 开始。
// 约定非空串 z[0]=|s|，空串返回空数组；时间和空间 O(|s|)。
vector<int> z_function(const string& s){
    int n=s.size();vector<int>z(n);if(n)z[0]=n;
    for(int i=1,l=0,r=0;i<n;++i){
        if(i<r)z[i]=min(r-i,z[i-l]);
        while(i+z[i]<n&&s[z[i]]==s[i+z[i]])++z[i];
        if(i+z[i]>r){l=i;r=i+z[i];}
    }
    return z;
}
```

**调用与说明**：z_function("aaaa") 返回 {4,3,2,1}。

## 4.3 Manacher：奇偶回文半径

[完整代码：4.3 Manacher：奇偶回文半径.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.3%20Manacher%EF%BC%9A%E5%A5%87%E5%81%B6%E5%9B%9E%E6%96%87%E5%8D%8A%E5%BE%84.cpp)

**用途与条件**：d1[i] 为以 i 为中心的奇回文半径，长度 2*d1[i]-1；d2[i] 为以 i-1 与 i 间隙为中心的偶回文半径，长度 2*d2[i]。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：时间 O(n)，空间 O(n)。

**易错点**：无需插入特殊字符，避免分隔符冲突。回文子串出现次数为 sum(d1)+sum(d2)，不等于不同回文串数量。

```cpp
// 返回 {奇回文半径 d1,偶回文半径 d2}，均为 0 下标。
// d1[i] 含中心 i，回文长度为 2*d1[i]-1；d2[i] 的中心在 i-1 与 i 之间，长度为 2*d2[i]。
// 空串返回两个空数组；时间和空间 O(|s|)。
pair<vector<int>,vector<int>> manacher(const string& s){
    int n=s.size();vector<int>d1(n),d2(n);
    for(int i=0,l=0,r=-1;i<n;++i){
        int k=i>r?1:min(d1[l+r-i],r-i+1);
        while(i-k>=0&&i+k<n&&s[i-k]==s[i+k])++k;
        d1[i]=k--;if(i+k>r){l=i-k;r=i+k;}
    }
    for(int i=0,l=0,r=-1;i<n;++i){
        int k=i>r?0:min(d2[l+r-i+1],r-i+1);
        while(i-k-1>=0&&i+k<n&&s[i-k-1]==s[i+k])++k;
        d2[i]=k--;if(i+k>r){l=i-k-1;r=i+k;}
    }
    return {d1,d2};
}
```

**调用与说明**："abba" 的 d2[2]=2，因此最长偶回文长度为 4。

## 4.4 双模字符串哈希

[完整代码：4.4 双模字符串哈希.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.4%20%E5%8F%8C%E6%A8%A1%E5%AD%97%E7%AC%A6%E4%B8%B2%E5%93%88%E5%B8%8C.cpp)

**用途与条件**：预处理后 O(1) 得到子串 [l,r) 哈希。相同参数构造的对象可跨串比较。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：预处理时间与空间 O(n)，单次查询 O(1)。

**易错点**：双哈希仍可能碰撞，不提供严格正确性保证。需要确定性时用 KMP、后缀数组等算法；比较时同时检查长度。

```cpp
struct StringHash {
    static constexpr i64 M1=1000000007,M2=1000000009,B=911382323;
    vector<i64>h1,h2,p1,p2;
    // 预处理字符串 s 的双模前缀哈希和幂表，字符串位置为 0 下标；时间和空间 O(|s|)。
    StringHash(const string&s):h1(s.size()+1),h2(s.size()+1),
        p1(s.size()+1,1),p2(s.size()+1,1){
        for(int i=0;i<(int)s.size();++i){
            int x=(unsigned char)s[i]+1;
            h1[i+1]=(h1[i]*B+x)%M1;h2[i+1]=(h2[i]*B+x)%M2;
            p1[i+1]=p1[i]*B%M1;p2[i+1]=p2[i]*B%M2;
        }
    }
    // 返回子串 s[l..r) 的两个模数下哈希，要求 0<=l<=r<=|s|；时间 O(1)。
    // 比较子串时需同时比较长度；即使双哈希相等，也仍存在碰撞可能。
    pair<i64,i64> get(int l,int r)const{
        return {(h1[r]-h1[l]*p1[r-l]%M1+M1)%M1,
                (h2[r]-h2[l]*p2[r-l]%M2+M2)%M2};
    }
};
```

**调用与说明**：StringHash h("abcabc"); h.get(0,3)==h.get(3,6)。

## 4.5 AC 自动机：多模式出现次数

[完整代码：4.5 AC 自动机：多模式出现次数.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.5%20AC%20%E8%87%AA%E5%8A%A8%E6%9C%BA%EF%BC%9A%E5%A4%9A%E6%A8%A1%E5%BC%8F%E5%87%BA%E7%8E%B0%E6%AC%A1%E6%95%B0.cpp)

**用途与条件**：小写字母 a-z，插入所有非空模式后 build，再统计各模式在文本中的出现次数。重复模式允许共用终止节点。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：设节点数 S、文本长 N、字符集大小 26：构建 O(26S)，匹配与反向累加 O(N+S)，空间 O(26S)。

**易错点**：build 补全转移后不能再 insert。count 返回按节点编号的出现次数，模式答案读其终止节点。不要逐字符沿 fail 链枚举全部后缀。

```cpp
struct Aho {
    struct Node{array<int,26>go{};int fail=0;};
    vector<Node>t{{}};vector<int>order;
    // 插入非空小写模式串 s，返回其终止节点编号；重复模式可返回同一节点。
    // 只能在 build 前调用，时间 O(|s|)。
    int insert(const string&s){
        assert(!s.empty());int u=0;
        for(char ch:s){int c=ch-'a';assert(0<=c&&c<26);
            if(!t[u].go[c]){t[u].go[c]=t.size();t.push_back({});}
            u=t[u].go[c];
        }return u;
    }
    // 在全部模式插入后构造 fail 指针并补全字符转移，记录 BFS 顺序 order。
    // 本实现应只调用一次，之后不能继续 insert；S 个节点耗时 O(26S)。
    void build(){
        queue<int>q;for(int v:t[0].go)if(v)q.push(v);
        while(!q.empty()){
            int u=q.front();q.pop();order.push_back(u);
            for(int c=0;c<26;++c){
                int v=t[u].go[c];
                if(v){t[v].fail=t[t[u].fail].go[c];q.push(v);}
                else t[u].go[c]=t[t[u].fail].go[c];
            }
        }
    }
    // 统计小写文本 s 中各自动机节点所代表模式的出现次数，允许重叠。
    // 需先 build；返回值按节点编号索引，模式答案取其 insert 返回的终止节点。
    // 时间 O(|s|+S)，不修改自动机，可以对不同文本重复调用。
    vector<i64> count(const string&s)const{
        vector<i64>cnt(t.size());int u=0;
        for(char ch:s){u=t[u].go[ch-'a'];++cnt[u];}
        for(int i=(int)order.size()-1;i>=0;--i){int v=order[i];cnt[t[v].fail]+=cnt[v];}
        return cnt;
    }
};
```

**调用与说明**：Aho ac; int p=ac.insert("aba"); ac.build(); ac.count("ababa")[p] 返回 2。

## 4.6 后缀数组与 LCP：倍增版

[完整代码：4.6 后缀数组与 LCP：倍增版.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.6%20%E5%90%8E%E7%BC%80%E6%95%B0%E7%BB%84%E4%B8%8E%20LCP%EF%BC%9A%E5%80%8D%E5%A2%9E%E7%89%88.cpp)

**用途与条件**：sa[i] 为第 i 小后缀的起点。lcp[i] 为 sa[i-1] 与 sa[i] 的 LCP，lcp[0]=0。支持任意字节串。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：使用比较排序的倍增：O(n log² n) 时间；Kasai 求 LCP 为 O(n)；空间 O(n)。

**易错点**：超大字符串可改计数排序倍增或 SA-IS。不同子串数 = n(n+1)/2 - sum(lcp)。任意两后缀 LCP 可对 lcp 建 RMQ。

```cpp
struct SuffixArray {
    vector<int>sa,rk,lcp;
    // 构造字符串 s 的后缀排序 sa、逆排名 rk 和相邻后缀公共前缀长度 lcp。
    // 均用 0 下标，lcp[0]=0，支持空串；比较排序倍增耗时 O(n log²n)，空间 O(n)。
    SuffixArray(const string&s){
        int n=s.size();sa.resize(n);rk.resize(n);lcp.assign(n,0);
        iota(sa.begin(),sa.end(),0);
        for(int i=0;i<n;++i)rk[i]=(unsigned char)s[i];
        vector<int>tmp(n);
        for(int k=1;k<n;k*=2){
            // 读取当前轮位置 i 的排名，超过字符串末尾时返回 -1，作为缺失后半段的最小排名。
            auto val=[&](int i){return i<n?rk[i]:-1;};
            // 比较后缀 a、b 的前后两段排名，每段长 k；供当前倍增轮排序与判断新排名。
            auto cmp=[&](int a,int b){return pair{rk[a],val(a+k)}<pair{rk[b],val(b+k)};};
            sort(sa.begin(),sa.end(),cmp);tmp[sa[0]]=0;
            for(int i=1;i<n;++i)tmp[sa[i]]=tmp[sa[i-1]]+cmp(sa[i-1],sa[i]);
            rk=tmp;if(rk[sa.back()]==n-1)break;
        }
        for(int i=0;i<n;++i)rk[sa[i]]=i;
        for(int i=0,h=0;i<n;++i){
            if(rk[i]==0){h=0;continue;}int j=sa[rk[i]-1];
            while(i+h<n&&j+h<n&&s[i+h]==s[j+h])++h;
            lcp[rk[i]]=h;if(h)--h;
        }
    }
};
```

**调用与说明**：SuffixArray a("banana"); a.sa 为 {5,3,1,0,4,2}。

## 4.7 后缀自动机：不同子串与出现次数

[完整代码：4.7 后缀自动机：不同子串与出现次数.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.7%20%E5%90%8E%E7%BC%80%E8%87%AA%E5%8A%A8%E6%9C%BA%EF%BC%9A%E4%B8%8D%E5%90%8C%E5%AD%90%E4%B8%B2%E4%B8%8E%E5%87%BA%E7%8E%B0%E6%AC%A1%E6%95%B0.cpp)

**用途与条件**：小写字母 a-z。每个状态代表长度区间 (len[link[v]],len[v]]。支持在线 extend，构建结束后统计 endpos 大小。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：固定字符集下构建 O(n)，空间 O(26n)；本版出现次数按长度排序，O(n log n)。

**易错点**：克隆状态自身贡献次数为 0。occurrences 使用副本累加，可以重复调用。不要把状态数误当不同子串数。

```cpp
struct SAM {
    struct Node{array<int,26>go;int link=-1,len=0;i64 cnt=0;
        // 创建自动机状态：所有字符转移设为 -1，其他字段使用默认初值。
        Node(){go.fill(-1);}};
    vector<Node>t{Node()};int last=0;
    // 在当前字符串末尾追加一个小写字母 ch，更新自动机、后缀链接和 last。
    // 必要时克隆状态，克隆自身出现次数为 0；固定字符集下整个构建过程为线性时间。
    void extend(char ch){
        int c=ch-'a',cur=t.size();assert(0<=c&&c<26);
        t.emplace_back();t[cur].len=t[last].len+1;t[cur].cnt=1;
        int p=last;
        while(p!=-1&&t[p].go[c]==-1){t[p].go[c]=cur;p=t[p].link;}
        if(p==-1)t[cur].link=0;
        else{
            int q=t[p].go[c];
            if(t[p].len+1==t[q].len)t[cur].link=q;
            else{
                int clone=t.size();t.push_back(t[q]);
                t[clone].len=t[p].len+1;t[clone].cnt=0;
                while(p!=-1&&t[p].go[c]==q){t[p].go[c]=clone;p=t[p].link;}
                t[q].link=t[cur].link=clone;
            }
        }last=cur;
    }
    // 返回当前字符串不同非空子串的数量，累加各非根状态代表的长度区间；时间 O(状态数)。
    i64 distinct()const{
        i64 ans=0;for(int v=1;v<(int)t.size();++v)ans+=t[v].len-t[t[v].link].len;
        return ans;
    }
    // 返回每个状态的 endpos 大小，即其代表的非空子串在当前字符串中的出现次数。
    // 用副本按长度降序累加，可重复调用；根状态的值不作为空串出现次数使用。
    // S 个状态耗时 O(S log S)，额外空间 O(S)。
    vector<i64> occurrences()const{
        vector<int>ord(t.size());iota(ord.begin(),ord.end(),0);
        // 按状态最大长度降序排序，使出现次数先从较长状态传给较短的后缀链接目标。
        sort(ord.begin(),ord.end(),[&](int a,int b){return t[a].len>t[b].len;});
        vector<i64>cnt;for(auto &v:t)cnt.push_back(v.cnt);
        for(int v:ord)if(t[v].link!=-1)cnt[t[v].link]+=cnt[v];return cnt;
    }
};
```

**调用与说明**：SAM s; for(char c:string("ababa")) s.extend(c); s.distinct()==9。查询模式时从根沿 go 走，失败为不存在，否则读取 cnt[state]。

## 4.8 最小表示法

[完整代码：4.8 最小表示法.cpp](../%E4%BB%A3%E7%A0%81/04_%E5%AD%97%E7%AC%A6%E4%B8%B2/4.8%20%E6%9C%80%E5%B0%8F%E8%A1%A8%E7%A4%BA%E6%B3%95.cpp)

**用途与条件**：返回字符串循环移位中字典序最小者的起点；空串返回 0。 字符串及其位置数组保留 0 下标；自动机状态编号也从 0 开始。

**复杂度**：时间 O(n)，空间 O(n)（复制双倍串）。

**易错点**：多个相同最小表示会返回其中最靠前的候选。用于环结构判等时还需比较长度。

```cpp
// 返回字典序最小循环移位的 0 下标起点；多个最优起点取最小者，空串返回 0。
// 返回位置而非字符串；时间 O(n)，复制双倍串使用 O(n) 空间。
int min_rotation(const string&s){
    int n=s.size();if(!n)return 0;string t=s+s;
    int i=0,j=1,k=0;
    while(i<n&&j<n&&k<n){
        if(t[i+k]==t[j+k]){++k;continue;}
        if(t[i+k]>t[j+k]){i+=k+1;if(i==j)++i;}
        else{j+=k+1;if(i==j)++j;}k=0;
    }
    return min(i,j);
}
```

**调用与说明**：min_rotation("baca") 返回 3，最小循环串为 "abac"。
