## 1.2 二分边界与答案二分

[完整代码：1.2 二分边界与答案二分.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.2%20%E4%BA%8C%E5%88%86%E8%BE%B9%E7%95%8C%E4%B8%8E%E7%AD%94%E6%A1%88%E4%BA%8C%E5%88%86.cpp)

**用途与条件**：使用开区间 (l,r) 二分，在先假后真的条件中找第一个 true。l 是不满足条件的边界，r 是满足条件的边界，两端可使用虚拟哨兵且不会调用 ok。对 1 下标数组 arr[1..n]，初始化 l=0、r=n+1；不存在则返回 n+1。

**复杂度**：O(log(r-l)) 次判定；空间 O(1)。

**易错点**：要求 l<r、r-l 不溢出，且区间内条件先假后真。初始 l、r 不参与检查；实际候选闭区间 [L,R] 应传入 L-1、R+1，并确保哨兵可表示。循环结束时 r 是第一个真，l 是最后一个假；返回初始 r 表示候选中不存在真。

```cpp
// 在开区间 (l,r) 中寻找第一个使 ok(x) 为真的值，不存在则返回初始 r。
// l 为假边界，r 为真边界；两端可为虚拟哨兵，不会调用 ok。
// 要求 l<r、r-l 不溢出，条件先假后真；判定次数为 O(log(r-l))。
// 对 arr[1..n]，传入 l=0、r=n+1；返回 n+1 表示不存在。
template <class Pred>
i64 first_true(i64 l, i64 r, Pred ok) {
    while (l + 1 < r) {
        i64 mid = l + (r - l) / 2;
        if (ok(mid)) {
            r = mid;
        }
        else {
            l = mid;
        }
    }
    return r;
}
```

**调用与说明**：有序数组 arr[1..n]：first_true(0, n + 1, [&](i64 mid) { return arr[mid] >= x; }) 返回第一个 >=x 的位置，不存在返回 n+1。答案二分：first_true(-1, 11, [](i64 x) { return x*x >= 30; }) 在候选 [0,10] 中返回 6。

## 1.3 离散化

[完整代码：1.3 离散化.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.3%20%E7%A6%BB%E6%95%A3%E5%8C%96.cpp)

**用途与条件**：输入数组 a[1..n]，排序去重得到 xs[1..m]，将原数值映射为从 1 开始的秩；不修改原数组。

**复杂度**：构造 O(n log n)，单次查询秩 O(log m)，空间 O(n)。

**易错点**：离散化保留大小关系，不保留距离；几何长度使用原坐标之差。输入数组至少包含占位 a[0]，其值不参与计算。

```cpp
// a[0] is unused; xs[0] is also unused.
// 将 a[1..n] 排序去重，返回带 0 号占位的有序值表 xs；不修改原数组。
// 要求 a 至少包含占位项；时间 O(n log n)，空间 O(n)。
template <class T>
vector<T> compress(const vector<T>& a) {
    vector<T> xs(a.begin() + 1, a.end());
    sort(xs.begin(), xs.end());
    xs.erase(unique(xs.begin(), xs.end()), xs.end());
    xs.insert(xs.begin(), T{});
    return xs;
}
// 返回 x 在有序离散值表 xs[1..m] 中的 lower_bound 位置，作为 1 下标的秩。
// 通常要求 x 已在值表中；否则返回插入位置，可能为 m+1。时间 O(log m)。
template <class T>
int rank_of(const vector<T>& xs, T x) {
    return lower_bound(xs.begin() + 1, xs.end(), x) - xs.begin();
}
```

**调用与说明**：compress(vector<int>{0,30,10,30}) 得到 {0,10,30}，rank_of(xs,30)==2。

## 1.4 前缀和

[完整代码：1.4 前缀和.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.4%20%E5%89%8D%E7%BC%80%E5%92%8C.cpp)

**用途与条件**：输入数组 a[1..n]，构造 pre[0]=0 的前缀和数组；闭区间 [l,r] 的和为 pre[r]-pre[l-1]，适合静态区间求和。

**复杂度**：构造时间和空间 O(n)，单次区间求和 O(1)。

**易错点**：输入数组至少包含占位 a[0]，其值不参与计算。要求 1≤l≤r≤n；原数组修改后前缀和不会自动更新，累加及区间和必须在 i64 范围内。

```cpp
// 由 a[1..n] 构造前缀和 pre，pre[0]=0；[l,r] 的和为 pre[r]-pre[l-1]。
// 忽略 a[0]，不修改 a；要求累加不溢出 i64，时间和空间均为 O(n)。
vector<i64> prefix_sum(const vector<i64>& a) {
    vector<i64> pre(a.size()); // pre[i]：a[1..i] 的和，pre[0]=0。
    for (int i = 1; i < (int)a.size(); ++i) {
        pre[i] = pre[i - 1] + a[i];
    }
    return pre; // sum[l,r] = pre[r]-pre[l-1]
}
```

**调用与说明**：auto pre = prefix_sum({0,1,2,3}); 得到 {0,1,3,6}；区间 [2,3] 的和为 pre[3]-pre[1]=5。

## 1.5 差分

[完整代码：1.5 差分.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.5%20%E5%B7%AE%E5%88%86.cpp)

**用途与条件**：输入数组 a[1..n]，构造差分数组 diff；通过 range_add 记录闭区间 [l,r] 加 v，所有操作结束后调用 restore 还原。适合批量区间加、最后统一取值。

**复杂度**：初始化与还原各 O(n)，单次区间加 O(1)，空间 O(n)。

**易错点**：diff 必须保留 n+2 项，容纳 r+1；最后一项为边界标记，不属于原数组。a[0] 的值不参与计算。差分及累加结果必须在 i64 范围内；还原不会修改 diff。

```cpp
// 由 a[1..n] 构造 n+2 项的差分数组，忽略占位 a[0]；不修改 a。
// 输入至少含 a[0]，允许 n=0；末项用于区间更新的边界标记，时间和空间 O(n)。
vector<i64> difference(const vector<i64>& a) {
    assert(!a.empty());
    int n = (int)a.size() - 1;
    vector<i64> diff(n + 2);
    for (int i = 1; i <= n; ++i) {
        diff[i] = a[i] - (i == 1 ? 0 : a[i - 1]);
    }
    return diff;
}
// 在差分数组 diff 上记录闭区间 [l,r] 加 v，不直接还原原数组；l>r 时不操作。
// 有效更新要求 l>=1 且 r+1 在数组内，通常分配 n+2 项；时间 O(1)。
void range_add(vector<i64>& diff, int l, int r, i64 v) {
    if (l > r) return;
    diff[l] += v;
    diff[r + 1] -= v;
}
// 将含 n+2 项的 diff 前缀累加，返回 a[1..n]，a[0]=0；忽略末项边界标记。
// 不修改 diff，可在后续继续更新并再次还原；时间和空间 O(n)。
vector<i64> restore(const vector<i64>& diff) {
    assert(diff.size() >= 2);
    int n = (int)diff.size() - 2;
    vector<i64> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        a[i] = a[i - 1] + diff[i];
    }
    return a;
}
```

**调用与说明**：auto diff = difference({0,1,2,3}); range_add(diff,2,3,5); auto a = restore(diff); 得到 {0,1,7,8}。初始数组全零时，可直接使用 vector<i64> diff(n+2)。

## 1.6 单调队列：滑动窗口最小值

[完整代码：1.6 单调队列：滑动窗口最小值.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.6%20%E5%8D%95%E8%B0%83%E9%98%9F%E5%88%97%EF%BC%9A%E6%BB%91%E5%8A%A8%E7%AA%97%E5%8F%A3%E6%9C%80%E5%B0%8F%E5%80%BC.cpp)

**用途与条件**：输入 a[1..n]，返回 ans[1..n-k+1]，ans[j] 是窗口 [j,j+k-1] 的最小值；a[0]、ans[0] 均为占位。要求 1≤k≤n。

**复杂度**：时间 O(n)，辅助空间 O(k)。

**易错点**：先删除已离开窗口的下标，再维护单调性；存下标才能判定过期。将 >= 改为 <= 可求最大值。

```cpp
// 返回 a[1..n] 每个长度为 k 的窗口最小值，ans[j] 对应 [j,j+k-1]。
// 输入和输出的 0 号项均占位，要求 1<=k<=n；时间 O(n)，队列空间 O(k)。
vector<i64> window_min(const vector<i64>& a, int k) {
    assert(1 <= k && k < (int)a.size());
    deque<int> q;
    vector<i64> ans(1);
    for (int i = 1; i < (int)a.size(); ++i) {
        while (!q.empty() && q.front() <= i - k) {
            q.pop_front();
        }
        while (!q.empty() && a[q.back()] >= a[i]) {
            q.pop_back();
        }
        q.push_back(i);
        if (i >= k) ans.push_back(a[q.front()]);
    }
    return ans;
}
```

**调用与说明**：window_min({0,4,2,3,1},2) 返回 {0,2,2,1}，第 0 项为占位。

## 1.7 随机数与防构造哈希

[完整代码：1.7 随机数与防构造哈希.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.7%20%E9%9A%8F%E6%9C%BA%E6%95%B0%E4%B8%8E%E9%98%B2%E6%9E%84%E9%80%A0%E5%93%88%E5%B8%8C.cpp)

**用途与条件**：为 unordered_map 的整数键提供带随机种子的哈希，降低固定碰撞构造的影响。

**复杂度**：单次哈希 O(1)；哈希表平均操作 O(1)，最坏复杂度仍无保证。

**易错点**：随机化不是确定性最坏复杂度保证。需要有序遍历或严格界限时用 map。reserve 能减少扩容。

```cpp
struct CustomHash {
    // 将 64 位整数 x 按 SplitMix64 步骤混合，返回确定性的 64 位散列值；时间 O(1)。
    static u64 mix(u64 x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }
    // 为整数键 x 计算带进程内固定随机种子的哈希值，供 unordered_map 等容器调用。
    // 同一进程内相同键得到相同结果；可降低固定碰撞构造的影响，但不保证无碰撞。
    size_t operator()(u64 x) const {
        static const u64 seed = chrono::steady_clock::now().time_since_epoch().count();
        return mix(x + seed);
    }
};
```

**调用与说明**：unordered_map<i64,int,CustomHash> mp; mp.reserve(200000); mp.max_load_factor(0.7); 使用固定种子 mt19937_64 rng(12345) 可复现对拍。

## 1.8 快速排序

[完整代码：1.8 快速排序.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.8%20%E5%BF%AB%E9%80%9F%E6%8E%92%E5%BA%8F.cpp)

**用途与条件**：将整数数组 a 的闭区间 [l,r] 原地按升序排序；数组采用 1 下标，a[0] 占位。排序整个数组调用 quick_sort(a,1,n)。

**复杂度**：平均时间 O(n log n)，最坏 O(n²)；递归栈平均 O(log n)，最坏 O(n)。

**易错点**：非稳定排序。固定选择中间位置的元素作为基准，特殊构造可能退化；保存基准值，不能引用交换过程中会改变的数组元素。递归区间为 [l,j] 和 [j+1,r]。l>=r 时直接返回，允许用 [1,0] 表示空数组。其他算法的排序继续使用标准库 sort。

```cpp
// 将 a[l..r] 原地按升序排序，无返回值；调用时保证区间下标合法。
// 数组采用 1 下标，a[0] 占位；l>=r 时不操作。
// 平均时间 O(n log n)，最坏 O(n²)；递归栈平均 O(log n)，最坏 O(n)。
void quick_sort(vector<int>& a, int l, int r) {
    if (l >= r) return;

    int i = l - 1, j = r + 1;
    int pivot = a[l + (r - l) / 2];  // 保存基准值，避免交换后基准改变。

    while (i < j) {
        do {
            i++;
        } while (a[i] < pivot);

        do {
            j--;
        } while (a[j] > pivot);

        if (i < j) {
            swap(a[i], a[j]);
        }
    }

    // 分区后，左区间元素不大于基准，右区间元素不小于基准。
    quick_sort(a, l, j);
    quick_sort(a, j + 1, r);
}
```

**调用与说明**：vector<int> a = {0,3,1,2,1}; quick_sort(a,1,4); 得到 {0,1,1,2,3}。也可只排序合法子区间，区间外元素保持不变。
