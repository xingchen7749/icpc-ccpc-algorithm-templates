## 1.2 二分边界与答案二分

[完整代码：1.2 二分边界与答案二分.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.2%20%E4%BA%8C%E5%88%86%E8%BE%B9%E7%95%8C%E4%B8%8E%E7%AD%94%E6%A1%88%E4%BA%8C%E5%88%86.cpp)

**用途与条件**：在单调谓词 false...false,true...true 上找第一个 true。搜索域为 [lo,hi)，hi 可以作为不存在的哨兵。 例外：lo、hi 是候选数值而非数组下标；搜索域仍为 [lo,hi)，hi 是无解哨兵。

**复杂度**：O(log(hi-lo)) 次判定；空间 O(1)。

**易错点**：先证明单调性，再确认端点含义。要求 hi-lo 在 i64 范围内。浮点二分固定迭代次数通常比只依赖 eps 更稳定。

```cpp
// 在候选区间 [lo,hi) 中寻找第一个使 ok(x) 为真的值，不存在则返回原 hi。
// 要求谓词先假后真，且 hi-lo 不溢出；调用 ok 的次数为 O(log(hi-lo+1))。
template<class Pred>
i64 first_true(i64 lo, i64 hi, Pred ok) {
    while (lo < hi) {
        i64 mid = lo + (hi - lo) / 2;
        if (ok(mid)) hi = mid;
        else lo = mid + 1;
    }
    return lo;
}
```

**调用与说明**：first_true(0, 11, [](i64 x){ return x*x >= 30; }) 返回 6；若所有候选均为 false，则返回上界哨兵。

## 1.3 离散化、前缀和与差分

[完整代码：1.3 离散化、前缀和与差分.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.3%20%E7%A6%BB%E6%95%A3%E5%8C%96%E3%80%81%E5%89%8D%E7%BC%80%E5%92%8C%E4%B8%8E%E5%B7%AE%E5%88%86.cpp)

**用途与条件**：输入数组 a[1..n]，离散化输出 xs[1..m]，秩从 1 开始。前缀和 s[0]=0，闭区间 [l,r] 的和为 s[r]-s[l-1]；差分执行 [l,r] 加。

**复杂度**：离散化 O(n log n)；前缀和与差分还原 O(n)，单次操作 O(1)。

**易错点**：离散化不保留距离；几何长度使用原坐标之差。差分数组分配 n+2 个位置以容纳 r+1。输入数组至少包含占位 a[0]，其值不参与计算。

```cpp
// a[0] is unused; xs[0] is also unused.
// 将 a[1..n] 排序去重，返回带 0 号占位的有序值表 xs；不修改原数组。
// 要求 a 至少包含占位项；时间 O(n log n)，空间 O(n)。
template<class T> vector<T> compress(const vector<T>& a) {
    vector<T> xs(a.begin()+1,a.end());
    sort(xs.begin(),xs.end());
    xs.erase(unique(xs.begin(),xs.end()),xs.end());
    xs.insert(xs.begin(),T{});return xs;
}
// 返回 x 在有序离散值表 xs[1..m] 中的 lower_bound 位置，作为 1 下标的秩。
// 通常要求 x 已在值表中；否则返回插入位置，可能为 m+1。时间 O(log m)。
template<class T> int rank_of(const vector<T>& xs,T x) {
    return lower_bound(xs.begin()+1,xs.end(),x)-xs.begin();
}
// 由 a[1..n] 构造前缀和 s，s[0]=0；[l,r] 的和为 s[r]-s[l-1]。
// 忽略 a[0]，不修改 a；要求累加不溢出 i64，时间和空间均为 O(n)。
vector<i64> prefix_sum(const vector<i64>& a) {
    vector<i64>s(a.size());
    for(int i=1;i<(int)a.size();++i)s[i]=s[i-1]+a[i];
    return s; // sum[l,r] = s[r]-s[l-1]
}
// 在差分数组 diff 上记录闭区间 [l,r] 加 v，不直接还原原数组；l>r 时不操作。
// 有效更新要求 l>=1 且 r+1 在数组内，通常分配 n+2 项；时间 O(1)。
void range_add(vector<i64>& diff,int l,int r,i64 v) {
    if(l>r)return;
    diff[l]+=v;diff[r+1]-=v;
}
```

**调用与说明**：compress({0,30,10,30}) 得到 {0,10,30}，rank_of(xs,30)==2。diff 分配 n+2 个位置，操作后从下标 1 到 n 累加还原。

## 1.4 单调队列：滑动窗口最小值

[完整代码：1.4 单调队列：滑动窗口最小值.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.4%20%E5%8D%95%E8%B0%83%E9%98%9F%E5%88%97%EF%BC%9A%E6%BB%91%E5%8A%A8%E7%AA%97%E5%8F%A3%E6%9C%80%E5%B0%8F%E5%80%BC.cpp)

**用途与条件**：输入 a[1..n]，返回 ans[1..n-k+1]，ans[j] 是窗口 [j,j+k-1] 的最小值；a[0]、ans[0] 均为占位。要求 1≤k≤n。

**复杂度**：时间 O(n)，辅助空间 O(k)。

**易错点**：先删除已离开窗口的下标，再维护单调性；存下标才能判定过期。将 >= 改为 <= 可求最大值。

```cpp
// 返回 a[1..n] 每个长度为 k 的窗口最小值，ans[j] 对应 [j,j+k-1]。
// 输入和输出的 0 号项均占位，要求 1<=k<=n；时间 O(n)，队列空间 O(k)。
vector<i64> window_min(const vector<i64>& a, int k) {
    assert(1 <= k && k < (int)a.size());
    deque<int> q; vector<i64> ans(1);
    for (int i = 1; i < (int)a.size(); ++i) {
        while (!q.empty() && q.front() <= i-k) q.pop_front();
        while (!q.empty() && a[q.back()] >= a[i]) q.pop_back();
        q.push_back(i);
        if (i >= k) ans.push_back(a[q.front()]);
    }
    return ans;
}
```

**调用与说明**：window_min({0,4,2,3,1},2) 返回 {0,2,2,1}，第 0 项为占位。

## 1.5 随机数与防构造哈希

[完整代码：1.5 随机数与防构造哈希.cpp](../%E4%BB%A3%E7%A0%81/01_%E5%9F%BA%E7%A1%80%E4%B8%8E%E6%8A%80%E5%B7%A7/1.5%20%E9%9A%8F%E6%9C%BA%E6%95%B0%E4%B8%8E%E9%98%B2%E6%9E%84%E9%80%A0%E5%93%88%E5%B8%8C.cpp)

**用途与条件**：为 unordered_map 的整数键提供带随机种子的哈希，降低固定碰撞构造的影响。

**复杂度**：单次哈希 O(1)；哈希表平均操作 O(1)，最坏复杂度仍无保证。

**易错点**：随机化不是确定性最坏复杂度保证。需要有序遍历或严格界限时用 map。reserve 能减少扩容。

```cpp
struct CustomHash {
    // 将 64 位整数 x 按 SplitMix64 步骤混合，返回确定性的 64 位散列值；时间 O(1)。
    static u64 mix(u64 x) {
        x += 0x9e3779b97f4a7c15ULL;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
        x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
        return x ^ (x >> 31);
    }
    // 为整数键 x 计算带进程内固定随机种子的哈希值，供 unordered_map 等容器调用。
    // 同一进程内相同键得到相同结果；可降低固定碰撞构造的影响，但不保证无碰撞。
    size_t operator()(u64 x) const {
        static const u64 seed = chrono::steady_clock::now()
                                   .time_since_epoch().count();
        return mix(x + seed);
    }
};
```

**调用与说明**：unordered_map<i64,int,CustomHash> mp; mp.reserve(200000); mp.max_load_factor(0.7); 使用固定种子 mt19937_64 rng(12345) 可复现对拍。
