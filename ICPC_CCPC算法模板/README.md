## 文件说明

代码目录与手册章节一一对应：章节目录使用两位章号，文件名使用手册小节序号和完整算法标题，例如 `代码/05_数学/5.1 快速幂.cpp`。文件名中的 `/` 等 Windows 禁用字符替换为全角字符；手册每个条目都提供完整代码链接。

- `算法模板手册.md`：完整正文，含使用条件、复杂度、代码、易错点和例子。
- `章节/`：按专题拆分的 Markdown，方便单独浏览。
- `代码/01_基础与技巧/1.1 比赛起手式与整数安全.cpp`：可直接开始写题的程序骨架。
- `代码/章节目录/*.cpp`：61 个完整算法程序及 `代码/01_基础与技巧/1.1 比赛起手式与整数安全.cpp` 起手式；每个算法均自带依赖，可单文件复制编译。两种逆元分别位于 `5.2.1 费马小定理求逆元.cpp` 和 `5.2.2 扩展欧几里得求逆元.cpp`。
- `测试/verify.cpp`：确定性样例、随机对拍和边界检查。
- `测试/*_adapter*.hpp`：自动生成的测试适配文件，将算法隔离后供既有测试使用；写题不需要这些文件。
- `验证报告.md`：实际运行结果与验证范围。

## 使用方法

推荐直接复制需要的 `.cpp`，在 `solve()` 中填写题目逻辑并调用算法；单独编译时可直接使用当前算法的名称。依赖实现已展开，不需要携带其他项目文件。默认读取测试组数 `T`，单组题删掉 `cin >> T;`。

例如：`g++ -std=c++17 -O2 "代码/05_数学/5.4 组合数：阶乘预处理与 Lucas.cpp" -o comb.exe`。

比赛现场可以复制手册中的某个代码段，连同第一节公共头文件放到提交文件中；使用整数别名时也复制对应的 using 定义；有依赖的条目要一并复制依赖。

普通数组、图和树顶点使用 `1..n`，数组区间为闭区间 `[l,r]`。输入数组分配 `n+1` 个位置，`a[0]` 仅占位（任意值均忽略），例如 `segmenttree s({0,10,20,30})` 表示三个数；`s.query(1,3)` 返回 60。线段树分为 `代码/02_数据结构/2.5.1 带懒标记线段树（segmenttree）.cpp` 和 `代码/02_数据结构/2.5.2 无懒标记线段树（SegTree）.cpp`，分别提供对应的类，可独立复制编译；这两版统一使用 `int`，需要时在标准头文件之后、类定义之前加 `#define int long long`。所有独立文件直接提供全局函数或类，例如 `qpow(...)`、`Dinic`，无需命名空间前缀。

字符串保留 0 下标和原有子串区间约定。多项式系数、掩码、DP 容量/前缀长度按其数学含义保留 0；无占位的结果列表、邻接表的边列表、几何循环顶点列表也从容器位置 0 存放。每个例外已在对应条目中说明，它们保存的原图顶点和原数组下标仍为 1 编号。

宏默认不启用。下标写 `int`；`i64`、`i128`、`u64` 分别表示 `long long`、`__int128_t`、`unsigned long long`。需要 64 位无穷大的模板自行定义 `const i64 INF = (1LL << 62);`；128 位算法按计算范围使用独立哨兵。每份程序的起手式都提供这三个别名，不提供公共无穷大常量。

这些算法文件面向 GNU C++17 单文件写题：每次复制一个文件，在 `solve()` 中填写逻辑后单独编译。文件不含重复包含保护、入口条件判断或命名空间包装；依赖实现已直接放入文件。不要通过 `#include` 合并完整程序，也不要将所有 `.cpp` 一起链接。

## 编译与验证

在本目录下，GNU C++17 环境可运行：

```text
g++ -std=c++17 -O2 测试/verify.cpp -o verify
./verify
```

Windows 上运行生成的 `verify.exe`。测试不依赖网络。

在上一级目录运行 `python verify_headers.py`，可验证所有独立程序的编译和运行；脚本保留原名。线段树专项测试为 `测试/verify_segmenttree.cpp`，增加 `-DWIDE_SEG` 可验证宽整数用法。

## 维护与再生成

上一级的 `handbook_data.py` 保存条目内容，`appendix.md` 保存附录，`build_handbook.py` 将它们同步生成完整手册、章节文件和完整算法程序。只依赖 Python 标准库：

```text
python build_handbook.py
```

可以直接编辑 Markdown 做笔记，但再次生成会覆盖正文、章节和代码文件。需要长期同步的修改请改 `handbook_data.py`；个性化笔记建议另存文件。

本版未声称通过所有在线评测；具体测试结论以验证报告为准。高级算法的前提、数值范围和性能限制均属于接口约定，使用前应阅读。
